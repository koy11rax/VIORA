# Изолированная проверка Linux bridge

`run.py` запускается **только внутри отдельной одноразовой Linux VM** с root,
`VIORA_ISOLATED_VM=1` и маркером `/run/viora-isolated-test`. На рабочем ПК его
запускать нельзя: на время теста меняются сеть и доверенный CA **гостевой ОС**.
Требуются установленные `/usr/lib/viora/{viora_tunnel,core/xray,core/sing-box}`,
Python 3, curl, openssl, iproute2, systemd-resolved, nftables и polkit пакета.

Тест создаёт локальный network namespace с VLESS WS TLS сервером, HTTPS echo и
DNS. Используются только fixture-адреса и временный тестовый CA. Проверка TLS
не отключается. Не используются подписки или реальные серверы пользователей.

Проверяются реальный TUN-трафик и DNS, all/only/except process routing, остановка,
авария frontend, повторное подключение и постоянная блокировка. Выходные
JSON-результаты не являются проверкой скорости или удалённого VPN-сервера.

Поскольку строгая блокировка временно закрывает SSH, запускать через `nohup`,
вывод перенаправить в отдельный журнал и затем прочитать `report.json` в каталоге,
переданном единственным аргументом. При обычном выходе `finally` снимает только
созданную тестом защиту, удаляет namespace/veth и временный CA. Если VM была
принудительно выключена во время теста, её следует удалить/восстановить целиком.
