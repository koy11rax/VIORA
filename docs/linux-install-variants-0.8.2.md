# VIORA Desktop 0.8.2 — постоянная защита

Windows: запусти Viora-Windows-0.8.2-Setup.exe, закрой предыдущую VIORA через трей перед обновлением. Установка сохраняет аккаунт, серверы и настройки. Служба и системный компонент защиты устанавливаются в защищённую папку Program Files/Viora/Engine.

Linux x86_64:

- Debian/Ubuntu: sudo apt install ./Viora-Linux-0.8.2-amd64.deb
- Fedora: sudo dnf install ./Viora-Linux-0.8.2-1.x86_64.rpm
- Arch: sudo pacman -U ./viora-bin-0.8.2-1-x86_64.pkg.tar.zst

Linux требует GTK 3, Secret Service, polkit, nftables и systemd-resolved, управляющий DNS. Для ранней защиты поддержаны systemd с NetworkManager или systemd-networkd. В GNOME может потребоваться расширение индикаторов; без трея крестик минимизирует окно. Fedora Atomic/Flatpak и OpenRC не входят в этот выпуск.

## Включение

Сначала импортируй подписку и сохрани серверы. Отключи VPN, открой «Настройки → Соединение и защита → Постоянная блокировка без VPN». Нажми «Включить защиту» и подтверди описание. В Linux подтверди запрос polkit. Состояние «Включена» показывается только после ответа системного компонента. Нажми «Подключиться» на главной.

Блокировка сохраняется при ручном отключении VPN, закрытии приложения, аварии движка и перезагрузке. Автоматический запуск самого VPN после перезагрузки ПК этим не добавлен: до запуска VIORA интернет останется заблокирован. «Автоподключение» применяется при открытии приложения.

При включённой блокировке прямые правила, российские сервисы, локальная сеть и исключённые программы блокируются. Выбранные для VPN программы продолжают использовать VPN. Режим не предназначен для раздачи интернета/маршрутизации другим устройствам: пересылка трафика блокируется. Loopback и необходимый DHCP сохраняются. Разрешён служебный зашифрованный запрос к фиксированному 1.1.1.1:443 только для получения IPv4-адреса VPN-сервера; обычный DNS приложений этим не исключается.

Подписки, Telegram, администрация и обновление серверов без действующего VPN могут быть недоступны при включённой защите. Для работы с ними без VPN сначала выключи блокировку. HWID и Android APK 0.7.4 не изменены.

## Отключение и восстановление

Отключи VPN и дождись остановки. В том же разделе нажми «Выключить защиту». Обычное отключение VPN, выход из VIORA и смена темы блокировку не снимают. Кнопка «Проверить состояние» запрашивает фактическое состояние; после ошибки оно отображается как неподтверждённое.

Если приложение или служба недоступны, можно снять только правила VIORA от имени администратора:

Windows — PowerShell от администратора:

```powershell
& "$env:ProgramFiles\Viora\Engine\viora_firewall.exe" disable
```

Linux:

```sh
sudo /usr/lib/viora/viora_tunnel --protection recover
```

Если Linux-компонент уже удалён вручную, аварийное восстановление:

```sh
sudo nft delete table inet viora_lockdown
sudo rm -f /var/lib/viora/protection.enabled
sudo systemctl daemon-reload
```

Команда nft может сообщить, что таблица уже отсутствует. Не сбрасывай всю конфигурацию firewall. Штатное полное удаление пакета снимает правила VIORA; обновление сохраняет включённую блокировку. Linux-установщик не включает защиту автоматически и не перезапускает сетевые службы. Если уже включённая защита не загрузится до сети, зависимости NetworkManager/systemd-networkd препятствуют их запуску: используй аварийное восстановление.

## Проверки и ограничения выпуска

Сборка и проверки кода выполняются без запуска VPN и без активации firewall по запрету владельца. Подготовлены проверки правил/IPC без обращения к реальной службе и проверка установочных пакетов. Эффективность блокировки на реальном трафике, восстановление и загрузка ОС с активной политикой не проверены. Это кандидат для приёмки, а не подтверждение отсутствия утечек.

Windows EXE/MSI, RPM и Arch-пакет пока без подписи издателя. Контрольные суммы прилагаются. Существующие ограничения маршрутизации многопроцессных программ/Flatpak сохраняются.
