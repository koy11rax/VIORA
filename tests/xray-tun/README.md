# Изолированная проверка TUN, SNI и DNS

```powershell
python tests/xray-tun/run.py --go <путь-к-Go-1.27.3>
```

Нужны исходники Xray с закреплённым commit `701af60772cda123492f86e383e1fdba066614a9` в `toolchains/xray-main/` и уже заполненный Go module cache. Скрипт проверяет SHA256 задействованных исходников, запрещает загрузку модулей и добавляет только тестовые файлы через временный Go overlay. Исходники ядра не изменяются.

Проверяются четыре сценария настоящего gVisor TUN handler → dispatcher/router/policy → freedom. Пакеты проходят через `LinkEndpoint` и копии байтов в Go channels; удалённая сторона работает через `net.Pipe`, с временным TLS-сертификатом в памяти. Клиент проверяет сертификат и имя. Системный DNS запрещён защитным resolver; неожиданный outbound отклоняется тестовым dialer. Системные сокеты, Wintun, VPN, установщик, службы и настройки сети не используются.

1. SNI и быстрый тестовый DNS: TLS и данные проходят, есть дополнительный DNS lookup.
2. Адрес без SNI и заблокированный тестовый DNS: TLS проходит без lookup.
3. SNI и тестовый DNS с задержкой1с: прежний `IPIfNonMatch` задерживает уже адресованный TCP, TLS получает ожидаемый таймаут500мс.
4. Та же задержка, но последняя маршрутизация `tcp,udp → proxy`: TLS проходит без дополнительного lookup. Для успешных сценариев предусмотрен запас2с.

Этот результат доказывает условную зависимость от повторного DNS и её устранение последним правилом. Он не доказывает причину конкретного сбоя Windows, исправность настоящего VLESS/WebSocket/DoH или реального VPN. Проверки порядка IPv6/DNS/domain/subnet/process и строгого режима находятся в `desktop/tunnel/config_test.go`.

Остальные функции в файлах `fixture_*` переиспользуют ранее проверенный виртуальный стенд. Runner запускает только `TestOfflineTunRoutingDNSGap`; общие исследовательские тесты в этих файлах не являются частью данной проверки.

Xray-core распространяется под MPL2.0. Его исходники не включены в эту папку: тесты вызывают закреплённую локальную копию и внутренние API через overlay. Сведения о ядре и лицензиях сохраняются в документации проекта.
