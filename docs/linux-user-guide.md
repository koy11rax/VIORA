# VIORA на Linux — установка и настройка 1.1.0

Инструкция для VIORA 1.1.0, сборка 37. Здесь — установка, подключение своей или сторонней подписки, редактирование ссылок, выбор программ и восстановление интернета. Для первого подключения достаточно установить пакет, импортировать ссылку и выбрать сервер.

## Подойдёт ли твоя система

Пакеты предназначены для Linux x86_64 с glibc 2.35 или новее. Интерфейс собран на Ubuntu 22.04. Один комплект бинарников упакован в DEB для Debian/Ubuntu, RPM для Fedora и пакет pacman для Arch. Это три формата установки, а не отдельные проверенные сборки под каждую версию этих дистрибутивов.

Если архитектура неизвестна, посмотри её в терминале:

```sh
uname -m
getconf GNU_LIBC_VERSION
```

Нужен результат x86_64 и glibc не ниже 2.35. ARM/aarch64 и 32-битные системы этим выпуском не покрыты.

Для работы нужны GTK 3, libsecret и разблокированная связка ключей Secret Service, AppIndicator/StatusNotifier для трея, polkit, nftables, iproute2, ca-certificates и systemd-resolved. Менеджер пакетов устанавливает объявленные зависимости. В минимальной системе дополнительно может потребоваться провайдер Secret Service, например GNOME Keyring, и агент polkit в графическом сеансе.

Для ранней постоянной блокировки без VPN нужны systemd и NetworkManager либо systemd-networkd. Установка этих пакетов как Flatpak, работа на OpenRC или Fedora Atomic не предусмотрены. Совместимость конкретных выпусков Fedora/Arch и разных рабочих столов требует проверки на них.

## Установка и обновление

Закрой VIORA через полный выход в меню трея. В терминале перейди в папку со скачанным файлом и выполни команду для своей системы.

Debian / Ubuntu:

```sh
sudo apt install ./Viora-Linux-1.1.0-amd64.deb
```

Fedora:

```sh
sudo dnf install ./Viora-Linux-1.1.0-1.x86_64.rpm
```

Arch:

```sh
sudo pacman -U ./viora-bin-1.1.0-1-x86_64.pkg.tar.zst
```

Те же команды подходят для обновления установленного пакета. Перед обновлением не удаляй аккаунт, профили, связку ключей или данные приложения. Обычное обновление сохраняет настройки, подписки, выбранные программы и существующий HWID. Полное удаление старого пакета перед обновлением не требуется: удаление снимает постоянную защиту, а штатное обновление сохраняет её выбранное состояние.

Приложение устанавливается в /usr/lib/viora. Сама установка не включает VPN или постоянную блокировку и не перезапускает сетевые службы.

## Первый запуск и подключение

1. Открой VIORA из меню приложений или командой viora.
2. Разблокируй системную связку ключей, если рабочий стол запросит это. Запускай интерфейс от обычного пользователя, без sudo.
3. Отключи другое активное VPN-подключение на время использования VIORA: два одновременно запущенных туннеля могут конфликтовать.
4. Нажми «Импорт» и добавь подписку или отдельный сервер по инструкции ниже.
5. Открой «Серверы», выбери полученный профиль и нажми «Подключиться» на главной.
6. Подтверди системный запрос polkit от VPN-компонента, если он появился. Повышенные права нужны отдельному помощнику, а не всему интерфейсу.
7. Дождись результата подключения. Открой обычный HTTPS-сайт и нужное приложение, например Telegram или Discord.

Статус запущенного туннеля сам по себе не доказывает доступность интернета. Если сайты не открываются, переходи к разделу устранения проблем, а не считай импорт или анимацию подтверждением работающего VPN.

Когда VPN уже включён, выбор другого сервера запускает переключение с переподключением. Дождись его завершения и не нажимай кнопку несколько раз подряд.

## Подписка нашего сервиса и аккаунт Telegram

Возьми актуальную HTTPS-ссылку своей подписки в боте. Для обычного подключения можно импортировать её прямо в VIORA — предварительная привязка Telegram для этого не требуется.

Для кабинета, срока подписки, устройств и продления открой «Моя подписка» или значок аккаунта и выполни вход через Telegram с подтверждением в боте. После входа можно загрузить свою подписку из аккаунта. Продление открывается кнопкой «Продлить подписку»: выбери тариф, используй реквизиты и инструкцию, которые показывает приложение, затем отслеживай статус заявки. Оплата и подтверждение обрабатываются сервисом; удаление ссылки в клиенте не отменяет подписку и платёж.

При загрузке и обновлении собственной подписки VIORA автоматически передаёт существующий HWID клиента. Занимается слот устройства согласно условиям подписки. Не сбрасывай идентификатор для обхода ошибки: если устройство отвязано или закончились слоты, разреши существующее устройство либо реши вопрос с лимитом в кабинете/боте. Сторонним провайдерам HWID VIORA не передаётся.

В нашей подписке обычный вариант подключения — WS TLS. Hysteria2 выбирай только если он действительно выдан тебе и есть в полученном списке. Наличие поддержки протокола в приложении не добавляет такой сервер в подписку автоматически.

## Импорт: ссылка, буфер, QR или файл

На главной нажми «Импорт». В окне «Добавить VPN» доступны:

- «Вставить из буфера» — сначала скопируй ссылку в боте или у своего провайдера.
- Ручное поле «Подписка или подключение» — вставь HTTPS-ссылку подписки, URI отдельного сервера либо поддерживаемый текстовый список.
- «QR из изображения» — выбери файл с QR-кодом, фото или скриншот. На Linux используется изображение; встроенное сканирование камерой относится к Android.
- «Из файла подписки» — открой текстовый список, Clash YAML или sing-box JSON.

Для HTTPS-ссылки нажми «Загрузить подписку», для распознанного URI/списка — «Добавить подключение». Посмотри название, протокол, число серверов и сообщение о несовместимых записях. Импорт может сохранить поддерживаемые записи и отдельно показать число пропущенных.

Поддерживаются VLESS, VMess AEAD, Trojan, Shadowsocks AEAD и Hysteria2. Схемы отдельных ссылок: vless://, vmess://, trojan://, ss://, hysteria2:// и hy2://. Подписка может содержать обычный список таких ссылок, один Base64/Base64URL-конверт, Clash YAML/JSON с proxies или sing-box JSON с outbounds.

Это не импорт произвольной VPN-конфигурации. WireGuard/OpenVPN, Hysteria1, TUIC, SSR, Shadowsocks-плагины и AEAD-2022, старый VMess с alterId не равным 0 и неподдерживаемые транспорты отклоняются. Для Hysteria2 поддерживаются проверяемый TLS, ALPN h3 и Salamander либо работа без обфускации; port hopping, настройки up/down и дополнительные варианты pinning сейчас не импортируются. Профили, отключающие проверку TLS, не принимаются.

Из структурированных файлов извлекаются только разрешённые поля серверов. Чужие правила DNS, входящие порты, команды и настройки контроллеров не заменяют настройки VIORA. Максимум — 200 серверов, текст/ответ до 1 МиБ и отдельная ссылка до 16 КиБ. [Подробные ограничения форматов](https://github.com/koy11rax/VIORA/blob/v1.1.0/docs/multi-protocol-import.md).

HTTPS-подписка должна быть доступна по прямой безопасной ссылке. Допускается ограниченное число HTTPS-перенаправлений; переход на HTTP и адреса с встроенным логином/паролем отклоняются. Если в файле нет поддерживаемых серверов или загрузка не удалась, прежние подключения сохраняются.

## Обновление серверов подписки

Нажми «Обновить подписку» на главной, если провайдер изменил параметры или список серверов. Ошибка обновления не должна стирать прежние рабочие профили.

Автоматическое обновление настраивается в «Настройки → Подписки и приватность → Обновлять подписки»: вручную, раз в час или раз в 6 часов. Оно работает, пока приложение открыто. Если постоянная блокировка уже включена, загрузка подписки без работающего VPN может быть недоступна — сначала подключись с сохранённым сервером либо осознанно выключи блокировку.

## Изменить или удалить сохранённую ссылку

1. Открой «Серверы» либо «Моя подписка».
2. Найди карточку «Ссылки подключений» и нажми «Управление подключениями».
3. На экране «Сохранённые подключения» выбери нужную запись в разделе «Подписки».
4. Нажми «Изменить ссылку». Полная секретная ссылка сначала скрыта; значок глаза показывает или скрывает её.
5. Вставь новый адрес вручную или кнопкой «Вставить из буфера» и нажми «Проверить и сохранить». «Отмена» оставит прежнюю запись.

Новая HTTPS-подписка сначала загружается и разбирается. При ошибке старая ссылка, её серверы и выбранный профиль остаются. Уже сохранённую в другой записи ссылку добавить повторно нельзя. Общие серверы, принадлежащие другому источнику, при изменении или удалении одного источника сохраняются.

Для удаления нажми «Удалить» у подписки и подтверди действие. Это удаляет её из VIORA, а не отменяет услугу у провайдера. Если удаляемый сервер сейчас используется, приложение сначала ждёт подтверждённого отключения. При ошибке остановки данные не удаляются. Постоянная блокировка без VPN при этом не отключается.

## Изменить отдельный сервер

На том же экране ниже есть раздел «Отдельные серверы». В нём находятся URI, не принадлежащие сохранённой подписке. Используй «Изменить сервер» или «Удалить сервер» и подтверди действие.

Для отдельного сервера проверяется формат новой ссылки. Это не сетевой тест доступности: после сохранения отдельно проверь подключение. Если профиль сейчас используется, VIORA попытается переподключиться с новыми параметрами. Сервер внутри подписки меняй через ссылку самой подписки — ручная правка отдельной копии не заменяет обновление у провайдера.

## VPN только для выбранных программ

Открой «Приложения» или «Настройки → Приложения». В обычном режиме доступны три варианта:

- «Все через VPN» — программы используют VPN с учётом правил маршрутизации.
- «Только выбранные через VPN» — отметь программы для VPN, остальные идут через основную сеть.
- «Выбранные напрямую» — отмеченные программы идут через основную сеть, остальные используют VPN.

Для двух режимов с выбором список не должен быть пустым. Выбранные программы показываются сверху. Если автоматический список неполный, нажми «Добавить программу» и укажи настоящий исполняемый файл, например /usr/bin/имя-программы, а не ярлык .desktop. Пути символических ссылок приводятся к фактическому файлу.

У браузеров, оболочек, лаунчеров и приложений с несколькими процессами может потребоваться выбор вспомогательных исполняемых файлов. Flatpak и похожие контейнеры могут мешать определению процесса; универсальная работа фильтра с ними не обещается. Если процесс определить нельзя, соединение в режиме выбора блокируется, а не получает произвольный обход.

Кнопка «Экспорт» копирует выбранный список в буфер. «Импорт» позволяет добавить записи из списка VIORA либо заменить выбор. Используй Linux-список: Android и Windows используют другие идентификаторы. После переноса между компьютерами проверь реальные пути программ. Изменения применяются после переподключения.

При включённой постоянной блокировке программы, выбранные напрямую или оставшиеся вне VPN, могут потерять интернет. Она не делает исключения для прямого доступа.

## Маршрутизация, российские сервисы и DNS

В разделе «Маршрутизация» добавляй правила для доменов, IP и портов и следи за их порядком. Варианты маршрута: VPN, напрямую или блокировка. Свои правила имеют приоритет перед встроенным списком российских сервисов. Применяй изменения переподключением.

В «Настройки → Соединение и защита» параметр «Российские сервисы напрямую» изначально включён. Он направляет через обычный интернет VK, Госуслуги, Одноклассники, Mail, Яндекс, банки и домены .ru / .рф / .su. Выключи его, если нужен другой маршрут. Это выбранное исключение из VPN, а не обещание полного охвата всех российских сайтов. В строгой постоянной блокировке прямой доступ запрещён.

«Доступ к локальной сети» позволяет работать с домашними устройствами в обычном режиме. При постоянной блокировке прямые исключения, включая локальную сеть, блокируются.

В «Настройки → DNS и IPv6» стандартный DNS использует Cloudflare по HTTPS через VPN. Для своего DNS укажи корректный IPv4-адрес. При ошибке VPN скрытого перехода на DNS провайдера не предусмотрено. IPv6 в этой версии блокируется в обоих вариантах настройки; полноценное туннелирование IPv6 не заявляется.

## Постоянная блокировка без VPN

Сначала импортируй подписку и проверь обычное соединение. Затем отключи VPN и открой «Настройки → Соединение и защита → Постоянная блокировка без VPN». Нажми «Включить защиту», подтверди системный запрос и дождись показанного состояния. Кнопка «Проверить состояние» запрашивает фактический ответ компонента.

После включения интернет без VPN блокируется даже после полного выхода из VIORA и перезагрузки. Российские сервисы, локальная сеть и выбранные напрямую программы тоже не получают свободный обход. Подписки, кабинет и другие сетевые запросы без VPN могут быть недоступны.

Подключение VPN само не выключает эту защиту. Для возврата обычного интернета отключи VPN, дождись остановки и нажми «Выключить защиту». Удаление ссылки или сервера не отменяет её выбранное состояние.

## Автоподключение, переподключение и трей

«Настройки → Приложение → Подключаться при открытии» включает попытку подключения к последнему выбранному серверу при запуске VIORA. Это не автозапуск VPN при загрузке Linux. Постоянная блокировка может уже действовать после загрузки, пока само приложение ещё не открыто.

«Восстанавливать соединение» в настройках защиты управляет ограниченными попытками восстановления после неожиданной остановки. Ручное отключение отменяет повторные попытки; при неудаче приложение показывает ошибку, а не бесконечно обещает соединение.

Крестик сворачивает приложение в трей. В меню значка доступны подключение/отключение, выбор сервера, подписки, пинг, настройки и полный выход. Полный выход останавливает VPN. В GNOME для отображения значка может потребоваться расширение индикаторов; если хоста трея нет, окно минимизируется, чтобы приложение оставалось доступным.

## Что означает проверка пинга

Кнопка «Проверить пинг» для поддерживаемых TCP-подключений проверяет TCP-доступность. Это не полный RTT до VPN-сервера и не измерение скорости туннеля. При активном VPN локальный адаптер может подтверждать TCP, поэтому такое число не выдаётся за задержку удалённого узла.

Hysteria2 использует UDP/QUIC: обычная TCP-проверка для него не выполняется. Его работу проверь реальным подключением и открытием сайтов. В «Помощь» можно посмотреть состояние соединения; автоматическая проверка утечек DNS/IPv6 ещё обозначена как разрабатываемая. Статус и анимация не заменяют сетевую проверку.

## Если что-то не работает

- **Не сохраняются аккаунт или серверы.** Разблокируй системную связку ключей и проверь наличие Secret Service, например GNOME Keyring. Не удаляй связку и данные VIORA для обхода ошибки.
- **Не появляется запрос Linux или отказано в доступе.** Проверь, что в графическом сеансе работает агент polkit и твоя учётная запись может подтверждать административные действия. Запуск всего интерфейса через sudo не заменяет настройку polkit.
- **Профиль не импортируется.** Скопируй полную актуальную ссылку без лишнего текста. Проверь формат, срок и лимит устройств. Поддержка протокола не означает поддержку всех его плагинов и параметров; отключать TLS-проверку для обхода ошибки нельзя.
- **Виден статус подключения, но сайты не открываются.** Проверь выбранный сервер, режим программ и свои правила. Убедись, что другой VPN отключён. Для диагностики можно осознанно выбрать «Все через VPN» и переподключиться, сохранив понимание постоянной блокировки. Проверь наличие systemd-resolved и настройки DNS. Не сбрасывай все системные маршруты или firewall.
- **Ошибка сертификата.** Проверь дату и время Linux, пакет системных CA и актуальность адреса/SNI у провайдера. Не включай insecure/skip-cert-verify и не отключай проверку имени сервера.
- **Hysteria2 не подключается.** Сеть может ограничивать UDP. Если в твоей подписке есть WS TLS, проверь его. Неподдерживаемые настройки Hysteria2 уточни у провайдера; не придумывай отсутствующие серверы.
- **После выключения VPN интернета нет.** Сначала проверь состояние постоянной блокировки. Если она включена, это ожидаемое поведение. Для обычной сети выключи её осознанно или используй восстановление ниже.

## Аварийное восстановление обычного интернета

Этот раздел нужен, если ты хочешь снять именно постоянную блокировку VIORA. После её снятия обычный прямой интернет снова может работать. Если интерфейс доступен, сначала отключи VPN и выполни полный выход через трей.

Для просмотра только правил VIORA без их изменения:

```sh
sudo nft list table inet viora_lockdown
```

Если интерфейс недоступен, используй предусмотренную команду восстановления:

```sh
sudo /usr/lib/viora/viora_tunnel --protection recover
```

Она снимает блокировку VIORA и её сохранённый флаг. Она не удаляет аккаунт, ссылки или выбранные программы. Если файл помощника уже удалён вручную и выполнить команду нельзя, восстановление из штатной Linux-инструкции ограничено таблицей и флагом VIORA:

```sh
sudo nft delete table inet viora_lockdown
sudo rm -f /var/lib/viora/protection.enabled
sudo systemctl daemon-reload
```

Сообщение об отсутствии таблицы означает, что её уже нет. Не используй nft flush ruleset, общий сброс iptables или удаление чужих правил: это затронет защиту других программ. Если сетевые службы остановились из-за ранней защиты и после восстановления сеть не вернулась, проверь их состояние штатными средствами своего дистрибутива или обратись в поддержку.

## Ручная приёмка сборки 37 на твоей системе

После установки пройди этот чек-лист на своём компьютере. Фактически выполненные разработчиком проверки перечислены отдельно в следующем разделе.

1. Проверь архитектуру через uname -m, установленную версию пакета и сохранность прежних профилей/аккаунта. Для версии используй dpkg-query -W viora, rpm -q viora или pacman -Q viora-bin. Убедись, что Secret Service разблокирован и подключения сохраняются после повторного открытия VIORA.
2. На тестовой записи проверь импорт и обновление подписки, изменение ссылки, отмену редактирования и ошибочную ссылку. Отмена или ошибка должны сохранить прежние данные. После осознанного удаления должны остаться подключения других источников, включая общие серверы.
3. Подключись и открой HTTPS-сайт в браузере, который выбран для VPN, затем нужные программы. Если используешь голосовую связь или другой UDP-трафик, отдельно проверь и его: открывшийся сайт не подтверждает работу голоса.
4. Переключи сервер при активном VPN, дождись переподключения, проверь отключение, возврат окна из трея и полный выход. Обычное отключение/выход не должно самовольно снимать включённую постоянную блокировку.
5. Осознанно проверь режимы «Только выбранные через VPN» и «Выбранные напрямую», свои правила и российские исключения. При выключенной постоянной блокировке прямые маршруты могут работать; при включённой они должны блокироваться. Сверяй результат с выбранным режимом.
6. Проверь «Подключаться при открытии»: после запуска приложения должна выполняться попытка соединения с последним сервером. Загрузка Linux без открытия VIORA сама по себе не запускает VPN.
7. Посмотри внешний IP через браузер, который действительно направлен в VPN, и сравни с ожидаемым выходным адресом сервера. Изменившийся IP или индикатор страны не доказывают отсутствие DNS/IPv6/WebRTC-утечек.
8. Проверку постоянной защиты с перезагрузкой проводи осознанно: сначала сохрани рабочий сервер, прочитай команды аварийного восстановления выше и обеспечь доступ к локальному терминалу администратора. Только затем включай блокировку и проверяй её после перезагрузки. До открытия VIORA прямой доступ должен быть закрыт; для возврата обычной сети используй явное выключение защиты или восстановление.
