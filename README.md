# VIORA VPN

VPN-клиент для Android, Windows и Linux. Графитовый интерфейс, фиолетовые акценты,
подписки своего сервиса и импорт других совместимых серверов.

## Возможности

- Импорт подписки или сервера по ссылке, из буфера обмена и QR.
- VLESS: WS TLS, XHTTP TLS и REALITY Vision.
- Telegram-вход, подписка, устройства и продление с инструкцией оплаты в приложении.
- Административный кабинет с серверной проверкой роли, платежами, пользователями и группами.
- Правила маршрутизации, выбор приложений, отключаемый прямой доступ к российским сервисам.
- Обновление подписки и TCP-пинг на главной, восстановление подключения и смена сервера.
- Android: уведомление с временем/скоростью/трафиком, отключение и плитка быстрых настроек.
- Windows/Linux: трей с быстрыми действиями и постоянная блокировка без VPN.
- Темы, настройка внешнего вида, анимации подключения и отключения.

Функции аккаунта и оплаты требуют работающего сервера VIORA и соответствующих прав.
В исходниках есть общий адаптер сервера, но нет рабочего бота, его базы, токенов,
ключей подписи или пользовательских подписок. Установка приложения не обновляет сервер.

## Защита и ограничения

Проверка TLS не отключена. Секреты хранятся через Android Keystore, Windows DPAPI
и Linux Secret Service. Подписка автоматически передаёт существующий HWID;
алгоритм привязки этим выпуском не меняется.

Статус подключения отражает состояние локального движка, а не гарантирует
доступность любого сайта. TCP-пинг также не доказывает работоспособность туннеля.
Прямые исключения намеренно обходят VPN; строгая системная блокировка их запрещает.
Постоянная защита сохраняется после закрытия программы. Инструкцию восстановления
нужно прочитать до её включения: [Windows/Linux](docs/desktop-user-guide-1.0.0.md).

APK подписан прежним ключом Android. Play Protect может предупреждать о внешней установке.
Windows EXE/MSI и Linux-пакеты пока без подписи издателя; SHA-256 не заменяет её.
Linux-пакеты Fedora/Arch используют общий бинарник, собранный на Ubuntu;
отдельная проверка запуска на Fedora/Arch пока не выполнена.

Результаты проверки и непроверенные сценарии:
[Android 1.0.2](docs/android-release-1.0.2.md),
[Windows 1.0.5](docs/windows-connectivity-1.0.5.md),
[Linux 1.0.5](docs/linux-release-1.0.5.md),
[Windows/Linux 1.0.0](docs/release-1.0.0.md).
Предыдущий подробный аудит: [отчёт](docs/security-audit-2026-10-22.md).
Успешные проверки не являются доказательством отсутствия всех уязвимостей или утечек.

## Сборка и разработка

Основной клиент — Flutter/Dart, Android-служба — Kotlin/Java и Go/Xray,
desktop-служба — Go, фильтры Windows — C++/WFP, серверный адаптер — Python.
Используются закреплённые исходники и контрольные суммы сетевого движка.

- [Сборка Android](docs/android-source-build.md)
- [Сборка Windows/Linux](docs/desktop-source-build-1.0.0.md)
- [Установка Linux 1.0.5](docs/linux-install-variants-1.0.5.md)
- [Воспроизведение проверок аудита](docs/audit-reproduction-2026-10-22.md)

Локальные проверки: `flutter analyze --no-pub`, `flutter test --no-pub`,
`go test ./...` и `go vet ./...` в desktop/tunnel, Python unit tests с тестовыми
зависимостями. CI выполняет проверки исходников; workflow Desktop UI формирует
только интерфейсный комплект, без полноценного установщика VPN.
