# VIORA VPN для Android — 0.7.4

Установочная версия для Android 8.0 и новее. Один APK поддерживает
arm64-v8a, armeabi-v7a и x86_64. Обновление устанавливается поверх предыдущей
VIORA с сохранением аккаунта и настроек.

## Возможности

- Импорт подписок и серверов по ссылке, из буфера обмена и QR-кода.
- Вход через Telegram, подписка, продление с инструкцией по оплате и устройства.
- Административный кабинет для подтверждённого владельца.
- Правила маршрутизации, выбор приложений и отключаемый прямой доступ
  к российским сервисам. Импорт и экспорт списка приложений.
- Обновление подписки и TCP-пинг на главной странице.
- Уведомление с временем, скоростью, трафиком и отключением VPN.
- Автоматическое переподключение при смене сети и сервера.
- Поддержка постоянного VPN и системной блокировки Android.
- Настройка внешнего вида, светлая и тёмная темы.

## Изменения 0.7.4

Исправлено объявление IPv6-возможностей VPN-интерфейса. Стандартный DNS работает
через HTTPS внутри VPN. Сохранены прежняя подпись APK и настройки приложения.

На проверенном телефоне работают браузер, Telegram и exteraGram, строгая защита,
переходы Wi-Fi/мобильная сеть и восстановление после перезагрузки.

## Перед установкой

Google Play Защита может показывать предупреждение: приложение распространяется
отдельным APK. Подпись APK проверена, но она не означает проверку Google Play.
При системной блокировке приложения вне выбранного VPN-списка теряют интернет.
IPv6 пока блокируется; передача данных через VPN использует IPv4.

Проверки на других моделях, отдельное завершение процесса системой и
инструментальная проверка утечек не проведены. Работа на каждом Android-устройстве
не гарантируется результатами проверки одного телефона.

В пакете находятся APK, инструкция INSTALL-RU.md, исходники, лицензии,
release.json и SHA256SUMS.txt. Для обычной установки нужен только APK.
