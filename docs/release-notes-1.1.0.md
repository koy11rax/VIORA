# VIORA 1.1.0 — сторонние подписки и Hysteria2

Выпуск для **Android и Windows**. Linux остаётся в прежней версии 1.0.5.

## Скачать

- [Android APK](https://github.com/koy11rax/VIORA/releases/download/v1.1.0/Viora-Android-1.1.0-release.apk)
- [Windows EXE](https://github.com/koy11rax/VIORA/releases/download/v1.1.0/Viora-Windows-1.1.0-Setup.exe)
- [Windows MSI](https://github.com/koy11rax/VIORA/releases/download/v1.1.0/Viora-Windows-1.1.0.msi)

## Что изменилось

- Импорт и подключение сторонних VLESS, VMess AEAD, Trojan, Shadowsocks AEAD и
  Hysteria2, включая Salamander. Поддерживаются совместимые сочетания протокола,
  транспорта и TLS; универсальность для произвольного VPN-формата не заявляется.
- Подписки HTTPS, списки URI/Base64, Clash YAML/JSON и sing-box JSON. Добавлено
  открытие файла подписки; доступны прежние буфер обмена и QR.
- Интерфейс показывает фактический протокол и количество несовместимых записей.
  Для Hysteria2 не используется ошибочная проверка TCP-порта.
- Исправлены запуск новых профилей из Android-плитки и чтение адреса Hysteria2.
- Android прекращает подключение при отказе защиты TCP/UDP-сокета.
- Существующие аккаунты, серверы, HWID, маршрутизация и выбор приложений сохраняются.
  Сторонним провайдерам HWID не передаётся. Проверка TLS не отключается.

## Проверки и ограничения

224 Flutter-теста прошли, 6 пропущены; анализатор без замечаний. Проверены реальные
локальные передачи через все пять протоколов, включая конфигурации, созданные самим
приложением, и отказ при неверных данных доступа/сертификатах. Windows MSI проверен
без установки: 36 файлов, версии, защищённые пути, ярлыки; встроенный MSI EXE совпал.
Подпись Android APK проверена, ключ остался прежним.

Физический Android, реальные удалённые серверы и Windows TUN в этой сборке не
проверялись. HAPP и сеть основного компьютера не переключались. Windows EXE/MSI
пока без подписи издателя. SHA-256 приложены и не заменяют подпись издателя.
