# Android 1.1.0 — сторонние подключения

Сохранён общий интерфейс VIORA и существующие профили, настройки приложений,
привязка устройства и быстрые настройки Android. Общий импорт поддерживает
валидированные профили VLESS, VMess AEAD, Trojan, Shadowsocks AEAD и Hysteria2.
Ограничения форматов описаны в `multi-protocol-release-1.1.0.md`.

## Нативные изменения

- Java больше не ожидает только `vnext`/`servers`: Hysteria2 имеет отдельные
  `settings.address`, `settings.port` и обязательную версию 2.
- Подключение из плитки Android принимает эти протоколы и сохраняет запрет
  обхода TLS-проверки и прежние ограничения размера/структуры конфигурации.
- Нативный Xray прекращает TCP/UDP dial, если Android отклонил защиту сокета.
  Код, исходный SHA-256 и процедура сборки сохранены в `patches/xray-android/`.
- Неиспользуемая тестовая зависимость Mockito удалена: её Byte Buddy ломал
  Android Jetifier при запуске unit-тестов. В приложение она не входила.

## Дополнение 02.11.2026 — управление ссылками, сборка 37

В общем интерфейсе Android/Windows/Linux добавлены редактирование и удаление
сохранённых HTTPS-подписок и отдельных URI серверов. Замена подписки применяется
атомарно после успешной загрузки. При ошибке сохраняются прежние ссылка и серверы;
общие серверы других подписок остаются. Удаление активного подключения требует
подтверждённой остановки. Ручное отключение VPN не отменяется поздним обновлением.

Секретные ссылки показываются только по явной кнопке редактора; уведомления не
содержат URL или текст внешних исключений. Общий lock защищает import/edit/delete,
обновление и загрузку из аккаунта. Найденные при независимом review зависание
native stop и поздний ответ account import исправлены и покрыты регрессиями.

Профильная проверка новой функциональности: 27 тестов пройдены, включая
незавершающийся native stop, раннее событие DISCONNECTED, запоздалые ответы,
замену ClientState, отмену/Back, сохранение выбора и общих профилей. Анализ Flutter
без замечаний. Нативный AAR с SHA-256 `8571167d...` не менялся и не пересобирался;
протокольные проверки от 30.10 относятся к тому же ядру.

Хеш APK выше относится к исторической сборке 36. Проверки физического Android,
системного TUN и удалённого VPN для сборки 37 пока не выполнялись.

Сборка 37 успешно собрана с обычными release/lint-задачами. `apksigner verify`
прошёл; сертификат остался прежним. Manifest подтверждает `versionName=1.1.0`,
`versionCode=37`, minSdk 26 и targetSdk 36. Все три встроенные Go-библиотеки
побайтно соответствуют прежнему AAR после штатного `llvm-strip --strip-unneeded`.
Предупреждения SDK XML и R8/Kotlin metadata остаются; fatal lint не найден.
