# VIORA Linux 1.0.0 (28)

Клиент Linux собирается из текущего Flutter-кода в отдельной Ubuntu 22.04 x86_64 VM. Виртуальная машина не содержит пользовательских подписок и не используется для подключения к производственному VPN.

Выпуск включает обновлённый графитово-фиолетовый интерфейс, подтверждаемые движком состояния подключения, аккаунт и администрирование, настройки маршрутов и выбор приложений. Исправлены восстановление выбора Linux-программ, обработка сбоя отдельной подписки и повторные записи неизменившихся профилей в защищённое хранилище. Настройки сохраняются через атомарную замену файла. Привязка HWID не меняется.

Форматы: Debian/Ubuntu DEB, Fedora RPM и Arch `.pkg.tar.zst`. Метаданные, права и байты полезной нагрузки проверяются после упаковки. Ни один из пакетов не включает VPN или системную блокировку во время сборки.

Установка, постоянная защита и восстановление описаны в [инструкции Linux 1.0.0](linux-install-variants-1.0.0.md). Пакеты без подписи издателя; SHA-256 прилагается. Публикуемый итоговый отчёт содержит фактические результаты сборки и ограничения проверок. Успешная сборка не подтверждает отсутствие DNS/IPv6/WebRTC-утечек или совместимость с каждой версией Fedora и Arch.
