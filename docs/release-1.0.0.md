# VIORA 1.0.0

Android, Windows и Linux используют последний согласованный графитовый интерфейс
с фиолетовыми акцентами. Настройки, подписки и схема HWID сохраняются.

## Исправления перед выпуском

- Настройки приложений Windows/Linux корректно восстанавливаются после запуска.
- Проверка службы Windows продолжает работать после временного сбоя IPC.
- Linux проверяет содержание правил постоянной защиты, а не только их количество.
- Windows проверяет параметры системных блокирующих фильтров и владельца защиты.
- Android корректно закрывает частично запущенный движок и синхронизирует состояние.
- Настройки сохраняются атомарно; одинаковые записи профиля не шифруются повторно.
- Ошибка одной подписки не стирает серверы остальных источников.
- Серверная выдача подписок защищена от параллельного повторного начисления.
- Обработка фото ограничена фактическим размером и разрешением, вынесена из event loop.

## Что требует отдельного внимания

Python-адаптер бота не обновляется установкой клиента. Изменённые серверные модули
нужно развёртывать отдельно; боевой сервер этой сборкой не изменяется.
Контрольные суммы подтверждают совпадение файлов, но не заменяют подпись издателя.
EXE/MSI и Linux-пакеты пока не имеют подписи издателя. APK подписывается прежним
ключом Android; предупреждение Play Protect может сохраняться.

Полный перечень проверок и ограничений будет дополнен фактическими результатами
сборки и проверки подключённого телефона перед публикацией.

## Подтверждённые результаты

- Flutter Windows: analyze без замечаний; 82 теста прошли, 5 capture-тестов пропущены.
- Серверный адаптер: 43 теста прошли с изолированным Pillow 13.0.0.
- Go desktop: тесты и vet прошли; тест установленной службы пропущен.
- WFP: CTest прошёл; 8 положительных и 104 отрицательных случая без применения правил.
- Windows: настоящий Release, MSI и EXE; 30 файлов MSI и защищённые пути проверены.
- Android: подписанный Release 1.0.0 (28) установлен поверх 0.7.4 без удаления данных;
  владелец подтвердил работу браузера и Telegram через VPN. Android видит настоящую
  foreground VPN-службу с постоянным уведомлением и действием отключения.
- Все три ELF-библиотеки финального APK совпадают с новым проверенным AAR после
  штатного NDK strip и содержат buildinfo Go 1.27.3.
- Linux: новый Release собран в Ubuntu 22.04 VM; clean-profile запуск 40 секунд
  и проверка отсутствующих динамических библиотек прошли. Итог упаковки указан отдельно.

Открытие браузера на телефоне через автоматизацию было отклонено автоматической
политикой. Сетевую работу подтвердил владелец вручную; измерение внешнего IP,
утечек, обрыва/перезагрузки и переходов сети для 1.0.0 этим не подменяется.
Полный аудит и ограничения: [проверка безопасности](security-release-1.0.0.md).
