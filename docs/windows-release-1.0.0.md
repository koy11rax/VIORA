# VIORA Windows 1.0.0 (28)

Собраны новый Flutter Release, Go/Xray 1.27.3, WFP-компонент, MSI и EXE-установщик.
Используется согласованный графитово-фиолетовый интерфейс. Настройки, аккаунт,
HWID, трей, маршруты и выбор приложений сохранены.

Исправлены восстановление путей программ и защитных настроек, возобновление
опроса службы после временного IPC-сбоя, атомарная запись при удержанном handle,
проверка WFP-фильтров и контроль владельца постоянной защиты через Windows SID.
Системный движок устанавливается в Program Files/Viora/Engine; публичные MSI
параметры не могут перенаправить его в произвольную папку. Папку интерфейса
можно выбирать. Идентичности компонентов и UpgradeCode сохраняются.

Проверены 30 файлов реальной MSI по SHA-256, служба, ярлыки, стандартная и
выбранная папка, отклонение подмены Engine и условие снятия защиты при полном
удалении. Установка пакета и запуск VPN/WFP на рабочем ПК не выполнялись.
Windows EXE/MSI пока без подписи издателя.

Flutter: analyze без замечаний, 82 теста пройдено, 5 capture-проверок пропущено.
Go: тесты и vet прошли; проверка установленной службы отдельно пропущена.
WFP: 8 положительных и 104 отрицательных случая проверки фильтров, CTest прошёл.
Эти проверки не подтверждают отсутствие утечек на реальном трафике.

Постоянная защита сохраняется после выхода/аварии/перезагрузки и блокирует прямые
исключения. Автозапуск самого VPN при загрузке ПК не добавлен. Старой защите без
записи владельца потребуется однократная административная миграция.
[Инструкция и восстановление](desktop-user-guide-1.0.0.md).
