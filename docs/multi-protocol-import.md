# Импорт сторонних подключений

VIORA использует общий валидатор профилей Android, Windows и Linux. Импорт
сам по себе не означает, что соединение с сервером уже проверено: состояние VPN
и результат проверки трафика показываются отдельно.

## Форматы

- Отдельные ссылки `vless://`, `vmess://`, `trojan://`, `ss://`,
  `hysteria2://` и `hy2://`.
- Список таких ссылок, по одной на строке; комментарии с `#` пропускаются.
- Один Base64/Base64URL-конверт со списком ссылок.
- Clash YAML/JSON с массивом `proxies`.
- sing-box JSON с массивом `outbounds` или непосредственно массивом серверов.
- HTTPS-подписка, возвращающая один из этих форматов.

Из JSON/YAML извлекаются только разрешённые поля подключения. Чужие DNS,
маршруты, правила, команды, входящие порты, селекторы и контроллеры не исполняются
и не заменяют настройки VIORA. Профили с неподдерживаемыми полями подключения
пропускаются с видимым числом пропусков. Если рабочих профилей нет, импорт
завершается ошибкой, а прежние серверы сохраняются.

## Поддерживаемые сочетания

| Протокол | Поддержка импорта |
| --- | --- |
| VLESS | TCP/WS/XHTTP с TLS; TCP REALITY Vision |
| VMess | AEAD, `alterId=0`, TCP/WS; шифры `auto`, `aes-128-gcm`, `chacha20-poly1305`; TLS или собственное AEAD без TLS |
| Trojan | TCP/WS с обязательным проверяемым TLS |
| Shadowsocks | SIP002 и старый Base64; AEAD `aes-128-gcm`, `aes-256-gcm`, `chacha20-ietf-poly1305` |
| Hysteria2 | QUIC/TLS, ALPN `h3`, без обфускации либо Salamander; пароль и `obfs-password` сохраняются раздельно |

Пока не поддерживаются Shadowsocks-плагины/SSR/AEAD-2022, старый VMess,
Hysteria1, TUIC, WireGuard/OpenVPN-конфигурации, gRPC, HY2 port hopping,
настройки HY2 up/down, дополнительный certificate pinning и сертификаты из
файлов. Опции `insecure`, `allowInsecure`, `skip-cert-verify`, отключающие
проверку TLS, отклоняются. Их нельзя тихо отбросить и выдать профиль за рабочий.

## Редактирование и удаление ссылок

Открой «Серверы» или «Моя подписка» → «Ссылки подключений» →
«Управление подключениями». Вкладка подписок показывает провайдера и число
серверов; «Отдельные серверы» содержит подключения, не принадлежащие подпискам.
Секретная ссылка скрыта в редакторе до нажатия кнопки показа. Доступны вставка
из буфера, сохранение и отмена.

Новая ссылка подписки сначала загружается и разбирается. Если это не удалось,
прежняя ссылка, серверы и выбор остаются. Ссылка, уже сохранённая в другой
подписке, отклоняется. Общие серверы другого источника не удаляются.
Изменение профиля внутри подписки выполняется через ссылку подписки; отдельные
URI редактируются в своей вкладке. Схема защищённого хранилища сохранена.

Удаление требует подтверждения. Если удаляемый сервер сейчас используется,
VIORA ждёт подтверждённого отключения; при ошибке или превышении времени
ожидания данные остаются. Удаление из приложения не отменяет оплату и
подписку у провайдера. Постоянная системная блокировка без VPN сохраняет
выбранное пользователем состояние.

## Защита загрузки и хранения

Загрузка использует обычную проверку HTTPS. Допускаются до трёх HTTPS-
перенаправлений; downgrade на HTTP, URL с учётными данными и циклы запрещены.
Каждый переход создаёт новый запрос. HWID и сведения об устройстве передаются
только собственной подписке VIORA, если и исходная, и текущая ссылка отвечают
проверке доверенного адреса. Сторонние провайдеры этих заголовков не получают.

Ограничения: 1 МиБ текста/ответа, 16 КиБ на ссылку, 200 уникальных серверов,
2000 кандидатов и 4000 строк. Необработанный текст ошибок URI/YAML/JSON,
пароли и секретные ссылки не включаются в сообщения об ошибках. Профили
сохраняются в прежнем защищённом хранилище без сброса аккаунта, HWID или подписок.

## Проверки парсера

30.10.2026: профильные Flutter-проверки (`profile_protocols_test.dart`,
`subscription_import_test.dart`, `profile_storage_test.dart`, `domain_test.dart`)
прошли: 40 тестов. Включены roundtrip всех пяти протоколов, URI со специальными
символами, Base64, Clash/sing-box, смешанные подписки, unsafe TLS, лимиты,
сохранение старых VLESS-профилей, HTTPS-переходы и отсутствие HWID у стороннего
провайдера. Статический анализ четырёх файлов — без замечаний.

Это результаты разбора/хранения и подставного HTTP-клиента, не проверка
удалённого VPN-туннеля. Результаты сетевых проверок и готовых сборок фиксируются
отдельно для фактически проверенных движков и платформ.
