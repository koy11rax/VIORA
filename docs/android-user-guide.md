# VIORA на Android

## Установка и обновление

Открой `Viora-Android-0.7.4-release.apk` на телефоне и установи обновление.
Удалять прежнюю VIORA не нужно: обновление подписано тем же ключом и сохраняет
аккаунт, серверы и настройки. Не очищай данные приложения перед обновлением.
Google Play Защита может показывать предупреждение для приложения вне магазина;
наличие подписи APK не гарантирует отсутствие этого предупреждения.

## Первое подключение

1. Свяжи Telegram в разделе аккаунта и загрузи свою подписку либо используй
   «Импорт» для ссылки подписки. Секретную ссылку не публикуй.
2. Выбери сервер в разделе «Серверы» и нажми «Подключиться» на главной.
3. Подтверди системный запрос Android на создание VPN.

На главной доступны обновление подписки и проверка TCP-пинга. Пинг проверяет
доступность порта сервера; успешный пинг сам по себе не подтверждает работу сайтов.
При смене сервера работающий VPN переподключается автоматически.

## Какие приложения идут через VPN

«Настройки → Приложения»:

- «Все через VPN» — весь трафик приложений через VPN с учётом правил маршрутизации.
- «Только выбранные» — отметь приложения, которым нужен VPN. Пустой список
  не подключается, чтобы случайно не изменить смысл выбранного режима.
- Режим исключений — выбранные приложения используют обычный интернет.

Выбранные приложения стоят в начале списка. Выбор можно импортировать и
экспортировать через буфер обмена. Изменения применяются после переподключения.
«Российские сервисы напрямую» в настройках соединения можно выключить;
собственные правила маршрутизации имеют приоритет.

## Защита при обрыве

Обычный режим «В пределах VPN-сессии» не требует постоянной блокировки Android.
Строгий режим требует обоих системных переключателей для VIORA:
«Постоянный VPN» и «Блокировать подключения без VPN». Сначала сохрани рабочее
подключение в обычном режиме, затем включи системные переключатели и подключись
в строгом режиме.

При системной блокировке приложения вне выбранного VPN-списка остаются без
интернета. Для использования другого VPN сначала выключи блокировку, затем
постоянный VPN для VIORA в настройках Android. Один телефон использует один
активный VPN одновременно.

## Если не подключается

Проверь доступность обычного интернета, обнови подписку, выбери другой сервер.
При режиме «Только выбранные» проверь, что нужное приложение отмечено.
Если включена системная блокировка, учитывай её действие на приложения вне VPN.
Не удаляй аккаунт и не очищай данные Telegram для обычной проверки соединения.

Уведомление VIORA показывает время, скорость и трафик; его нажатием можно открыть
приложение, отдельной кнопкой — отключить VPN. Системное служебное уведомление
Android может вести в настройки и существует отдельно от уведомления VIORA.

Подписка, устройства и продление доступны в аккаунте. Раздел администрирования
появляется для подтверждённого владельца; права проверяет сервер.
