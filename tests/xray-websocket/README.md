# Автономные регрессии WebSocket и TLS sniffing

Тесты вызывают настоящий `websocket.Dial` из закреплённого Xray
`701af60772cda123492f86e383e1fdba066614a9`. Подменяется только системный
диалер внутри отдельного тестового процесса. Первый диалер записывает срок
контекста и возвращает ошибку; второй предоставляет поток в памяти, который
принимает ClientHello и возвращает EOF. Сокеты ОС, VPN, службы, маршруты и
сетевые настройки не используются. Глобальный диалер восстанавливается
после каждого теста; эти тесты нельзя запускать параллельно.

Требуются локальный Go 1.27.3 и заранее заполненный кеш модулей с зависимостями
из `go.mod`/`go.sum`. `run.py` запрещает загрузки только своим дочерним
процессам, не меняя глобальные настройки Go.

Из корня репозитория:

```text
python tests/xray-websocket/run.py --go <путь-к-локальному-go>
python tests/xray-websocket/run.py --go <путь-к-локальному-go> --verify-baseline
```

Первая команда проверяет исправленный overlay и должна завершаться успешно.
Вторая дополнительно требует два ожидаемых провала исходной версии, затем
два успешных теста исправленной. Прямой `go test` без overlay проверяет старую
реализацию и поэтому не является командой обычной проверки CI.

`scripts/build-desktop-core.ps1` применяет тот же overlay к Windows и Linux
и запускает исправленные регрессии, если не указан `SkipTests`.

Проверяемые дефекты:

- Вызов TCP/uTLS использовал внешний контекст вместо восьмисекундного
  контекста Gorilla. Проверяется срок, реально полученный диалером.
- Ошибка TLS возвращалась без закрытия полученного соединения. Проверяется
  вызов `Close` после неудачного рукопожатия.
- Неполная запись ClientHello ошибочно считалась неизвестным протоколом.
  Проверяется ответ настоящего TLS sniffer для частей запроса и сохранение
  распознанного имени после получения полной записи. Применяется второй
  проверяемый overlay `tls_sniff.go`.

Это проверка таймаута и владения ресурсом. Она не доказывает работоспособность
реального VPN, исправление конкретного сетевого сбоя или рост пропускной
способности. Android в этой правке не меняется.
