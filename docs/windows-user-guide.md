# VIORA 1.1.0 для Windows — установка, подключение и настройки

Инструкция для Windows 10/11 x64, VIORA 1.1.0, сборка 37. Здесь описаны установка, подключение своей подписки, управление ссылками и настройки защиты. Основной способ подключения сервиса VIORA — WS TLS. Другие подключения доступны, если они действительно выданы в твоей подписке.

### 1. Скачать приложение

- [Установщик VIORA для Windows — EXE](https://github.com/koy11rax/VIORA/releases/download/v1.1.0/Viora-Windows-1.1.0-Setup.exe) — основной вариант установки.
- [Пакет Windows Installer — MSI](https://github.com/koy11rax/VIORA/releases/download/v1.1.0/Viora-Windows-1.1.0.msi) — альтернативный вариант. Устанавливать оба файла не нужно.
- [Страница выпуска 1.1.0](https://github.com/koy11rax/VIORA/releases/tag/v1.1.0) — описание версии и контрольные суммы файлов.

Установщик этой версии не имеет цифровой подписи издателя. Windows или SmartScreen могут показать предупреждение. Проверь источник загрузки и, при необходимости, контрольную сумму из выпуска. Совпадение суммы подтверждает совпадение файла, но не заменяет подпись издателя. Если защита блокирует запуск, не отключай её: передай точный текст предупреждения владельцу сервиса или администратору компьютера.

### 2. Установить или обновить VIORA

1. Если VIORA уже установлена, отключи VPN. Найди значок VIORA в области уведомлений рядом с часами; скрытые значки открываются стрелкой. Нажми правой кнопкой и выбери **Выйти из VIORA**. Крестик окна только сворачивает приложение в трей.
2. Запусти официальный установщик. Выбери папку для самого приложения и заверши установку. Для установки или обновления системной службы Windows запросит права администратора.
3. Открой VIORA через ярлык. При обычном подключении уже установленная служба не требует подтверждения администратора каждый раз.
4. При обновлении не удаляй данные приложения и не сбрасывай HWID. Аккаунт, сохранённые подписки, идентификатор устройства и настройки используют прежнее защищённое хранилище.

Интерфейс можно установить в выбранную папку. Системный движок и служба размещаются отдельно, в защищённой папке `%ProgramFiles%\Viora\Engine`; переносить её вручную не нужно. В сборке 37 исправлены границы обновления установщика: переход с предыдущей сборки 1.1.0 на новую сборку 1.1.0 больше не должен отклоняться только из-за совпадения номера версии.

Если включена постоянная блокировка без VPN, после отключения соединения интернет останется заблокирован. Это сохранённая настройка защиты. Если для обновления нужен обычный интернет, сначала явно выключи эту защиту в VIORA, как описано ниже.

### 3. Первое подключение к VIORA VPN

1. Открой **Моя подписка** и нажми **Связать Telegram**. В боте сравни код входа с кодом приложения, подтверди вход и вернись в VIORA. Подтверждай только вход, который начал сам.
2. В аккаунте нажми **Загрузить мою подписку**. Можно обойтись и без привязки Telegram: скопировать свою HTTPS-ссылку подписки из бота и добавить её через **Импорт**.
3. В разделе **Серверы** выбери выданный сервер. Для сервиса VIORA основной вариант — **WS TLS**. Hysteria2 используй только тогда, когда такое подключение есть в списке твоей подписки.
4. На главной нажми **Подключиться** и дождись завершения подключения. Затем открой обычный HTTPS-сайт и нужное приложение: так проверяется передача трафика, а не только состояние кнопки.

Ссылка подписки содержит доступ к серверам. Не публикуй её, не отправляй в общий чат и не прикладывай целиком к скриншотам ошибок. Для собственной подписки VIORA сведения об устройстве и HWID передаются автоматически. Смена сети сама по себе не создаёт новый слот устройства. Сторонним провайдерам идентификатор VIORA не передаётся.

### 4. Импорт: ссылка, буфер, файл или QR

Открой **Импорт → Добавить VPN** и выбери способ:

- **Вставить из буфера** — если ссылка или список подключений уже скопированы.
- **QR из изображения** — выбери файл с QR-кодом. В Windows это импорт изображения; сканирование камерой относится к Android.
- **Из файла подписки** — открой TXT, Clash YAML/JSON или sing-box JSON с поддерживаемыми подключениями.
- Поле **Подписка или подключение** — вставь HTTPS-ссылку подписки либо отдельную URI вручную.

Для подписки нажми **Загрузить подписку**, для отдельных записей — **Добавить подключение**. Предпросмотр показывает протокол, число серверов и количество несовместимых записей. Если подходящих записей нет, импорт завершается ошибкой; прежние серверы сохраняются. Импортированный профиль ещё не означает успешного соединения с удалённым сервером.

Поддерживаются VLESS, VMess AEAD, Trojan, Shadowsocks AEAD и Hysteria2. Можно импортировать отдельные ссылки `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` или `hy2://`, список по одной ссылке на строке, список в Base64/Base64URL и HTTPS-подписку с поддерживаемым содержимым.

Поддержка протокола не означает поддержку всех его расширений. Например, не поддерживаются Shadowsocks-плагины, SSR/AEAD-2022, старый VMess, Hysteria1, TUIC, WireGuard/OpenVPN, HY2 port hopping и конфигурации, отключающие проверку TLS. Из файлов извлекаются разрешённые поля серверов; чужие DNS, маршруты, команды и контроллеры не подменяют настройки VIORA. Полный перечень сочетаний — в [описании форматов импорта](https://github.com/koy11rax/VIORA/blob/v1.1.0/docs/multi-protocol-import.md).

### 5. Обновить подписку

Нажми **Обновить подписку** на главной или **Обновить подписки** в меню трея. Полученные адреса и параметры обновятся из сохранённых источников. При сетевой ошибке прежние серверы сохраняются: не удаляй рабочую подписку только ради повторной попытки.

Интервал автоматического обновления настраивается в **Настройки → Подписки и приватность**. Обновление работает, пока приложение открыто, в том числе свёрнуто в трей. Если провайдер отозвал устройство, повторный импорт той же ссылки не восстанавливает разрешение: потребуется действие владельца подписки.

### 6. Изменить или удалить сохранённую ссылку

Открой **Серверы** или **Моя подписка**, найди карточку **Ссылки подключений** и нажми **Управление подключениями**. На странице **Сохранённые подключения** есть разделы **Подписки** и **Отдельные серверы**. В списке подписок показаны адрес провайдера и число серверов, без полного секретного URL.

Чтобы заменить подписку:

1. Выбери **Изменить ссылку**. Поле скрыто; при необходимости нажми **Показать ссылку** или **Вставить из буфера**.
2. Вставь новую HTTPS-ссылку и нажми **Проверить и сохранить**.
3. Дождись загрузки и разбора. Новая ссылка и её серверы заменят старые только при успешной проверке. При ошибке или отмене прежние данные останутся. Ссылка, уже сохранённая как другая подписка, не перезаписывает её.

Чтобы убрать источник, нажми **Удалить** и внимательно прочитай подтверждение. Удалятся эта ссылка и серверы, принадлежащие только ей. Подключения других подписок, в том числе общие с удаляемой, сохранятся. Отдельные подключения, не входившие в удаляемую подписку, тоже останутся.

Если удаляемый сервер используется сейчас, VIORA сначала ждёт подтверждённого отключения. Если отключение не подтвердилось, данные сохраняются. Удаление ссылки из приложения не отменяет оплату, аккаунт или подписку у провайдера и не выключает постоянную системную блокировку.

В разделе **Отдельные серверы** можно изменить URI или удалить вручную добавленное подключение, которое не принадлежит подписке. Сервер внутри подписки меняется через её URL или обновление у провайдера. Проверка URI при редактировании проверяет формат, а не доступность удалённого сервера. Повторный ручной импорт совершенно той же URI не создаёт отдельную независимую копию её происхождения.

### 7. Статус, смена сервера и проверка пинга

Во время подключения и отключения VIORA показывает переходное состояние и анимацию. Дождись результата; не запускай параллельно другой системный VPN. Если VPN уже работает и ты выбираешь другой сервер, приложение останавливает прежнее соединение и запускает выбранное заново. При ошибке ориентируйся на сообщение и итоговый статус, а не на цвет анимации.

На главной доступны время соединения, сервер и счётчики трафика. Эти данные помогают видеть работу сессии, но сами по себе не доказывают доступность каждого сайта. После смены сервера проверь нужное приложение ещё раз.

Кнопка **Проверить пинг** выполняет TCP-проверку там, где она применима. Это не измерение полной задержки через VPN и не тест скорости. При включённом туннеле быстрый ответ может относиться к локальному виртуальному адаптеру: значение вроде 6 мс не подтверждает задержку до удалённого сервера. Hysteria2 работает через UDP/QUIC; обычная TCP-проверка не подтверждает его доступность.

### 8. Трей и полное закрытие приложения

Крестик окна скрывает VIORA в области уведомлений, оставляя приложение и соединение работающими. Правый клик по значку открывает меню: **Открыть VIORA**, **Подключиться / Отключить VPN**, **Выбрать сервер**, **Обновить подписки**, **Проверить пинг**, **Настройки**, **Выйти из VIORA**. В меню также доступны состояние, время соединения и показатели трафика/скорости.

**Выйти из VIORA** полностью завершает приложение и останавливает VPN. Постоянная блокировка без VPN при этом сохраняется. Для Windows эта инструкция использует окно и трей; постоянное уведомление с кнопками, как в Android, здесь не обещается.

### 9. Какие программы идут через VPN

Открой **Приложения**, добавь нужные EXE через **Добавить программу** и выбери режим:

- **Все через VPN** — приложения участвуют в VPN, с учётом правил маршрутизации и явно разрешённых исключений.
- **Только выбранные через VPN** — выбранные EXE используют VPN, остальные работают напрямую, если постоянная блокировка это разрешает.
- **Выбранные напрямую** — выбранные EXE обходят VPN, остальные участвуют в VPN.

Для двух режимов с выбором нужен непустой список. Добавляй фактический исполняемый файл программы; у приложений с несколькими процессами могут быть отдельные EXE. Если программа не работает, проверь её путь и выбранный режим. Изменения применяются при новом подключении.

Кнопка **Экспорт** копирует список выбранных приложений в буфер. **Импорт** читает его из буфера и предлагает **Добавить** к текущему списку либо **Заменить список**. Перед заменой проверь подтверждение. При переносе на другой компьютер пути EXE могут отличаться — экспорт списка не устанавливает сами программы.

### 10. Маршрутизация и российские сервисы

В **Настройки → Соединение и защита** есть переключатель **Российские сервисы напрямую**, включённый по умолчанию. Он направляет обычным интернетом перечисленные сервисы и домены, включая VK, Госуслуги, Одноклассники, Mail, Яндекс, банки и домены .ru / .рф / .su. Это правило по известным доменам и спискам, а не распознавание любого российского сервиса. При необходимости выключи его и переподключись.

В разделе **Маршрутизация** можно добавлять правила по домену, IP/подсети или порту/диапазону с действием **Через VPN**, **Напрямую** или **Блокировать**. Первое подходящее включённое правило определяет маршрут; доменное правило включает поддомены. Порядок меняется кнопками **Выше / Ниже**. Твои правила имеют приоритет перед встроенным списком российских сервисов. DNS в этих режимах остаётся через VPN.

Правила начинают действовать при следующем подключении и учитывают выбранный режим приложений. Постоянная блокировка сильнее разрешения «напрямую»: она блокирует выход исключённых приложений, российских сервисов и локальной сети вне туннеля. Если тебе нужны прямые исключения, учитывай это перед включением строгой защиты.

### 11. Постоянная блокировка без VPN

Это отдельная системная настройка: она запрещает обычный интернет вне разрешённого VPN-пути. Она сохраняется при ручном отключении VPN, закрытии VIORA, остановке движка и перезагрузке Windows. Обычная кнопка **Отключить VPN** не снимает эту политику.

1. Сначала убедись, что подписка загружена и соединение работает. Отключи VPN и дождись завершения.
2. Открой **Настройки → Соединение и защита → Постоянная блокировка без VPN**.
3. Нажми **Включить защиту**, дождись результата и при необходимости нажми **Проверить состояние**.
4. Подключи VPN и проверь нужные программы. Прямые исключения и доступ к домашним устройствам при этой политике могут быть недоступны.

Чтобы осознанно вернуться к обычному интернету, отключи VPN и нажми **Выключить защиту** в том же разделе. Проверь итоговое состояние. Если защита включена, а туннель не работает, загрузка подписок, вход в аккаунт и оплата тоже могут оказаться недоступны.

Настройка **Автоподключение при открытии** запускает соединение при открытии VIORA. Она не означает автоматический запуск приложения при входе в Windows. После перезагрузки с постоянной блокировкой интернет может оставаться недоступным, пока ты не откроешь VIORA и VPN не подключится. Режим не предназначен для настройки раздачи интернета другим устройствам.

### 12. Telegram, устройства и продление

Привязанный Telegram открывает данные собственного аккаунта VIORA. В аккаунте можно посмотреть срок подписки, **Загрузить мою подписку**, **Управлять устройствами**, **Обновить аккаунт** и открыть бота. Если данные недавно изменились, обнови аккаунт и подписку.

В **Устройства подписки** показаны занятые слоты, названия устройств и доступные сведения об обновлении. Новое устройство привязывается при загрузке своей подписки. Отвязывай устройство при замене или потере; не удаляй действующий ПК ради исправления сетевой ошибки. Если этот ПК уже отозван, восстановить разрешение должен владелец подписки доступным ему способом. Не сбрасывай HWID для обхода ограничения.

Нажми **Продлить подписку в приложении**, выбери тариф и следуй актуальной инструкции, полученной от сервера. Реквизиты и комментарий копируй из созданной заявки. Только после реального перевода нажми **Я оплатил**, затем проверяй **Обновить статус**. Заявка ожидает подтверждения; кнопка не выполняет банковский перевод и не означает автоматическое зачисление. Не делай повторный платёж только из-за ожидания проверки.

Раздел **Администрирование** появляется для аккаунта, которому сервер выдал соответствующую роль. Обычный вход через Telegram не делает пользователя администратором. Если у владельца раздел не появился, проверь, что вошёл в нужный Telegram-аккаунт, обнови аккаунт и обратись к владельцу серверной части. Изменение локальных настроек роль не выдаёт.

### 13. Другие настройки

В **Соединение и защита** можно настроить восстановление после неожиданной остановки движка/службы, ожидание подключения, число попыток, MTU и доступ к локальной сети. Ручное отключение отменяет повторные попытки соединения. DNS, MTU и маршруты применяются при подключении; после изменения переподключись.

В разделе **DNS и IPv6** учитывай пояснения выбранного режима. В **Подписки и приватность** можно посмотреть HWID и параметры обновления. Не отправляй секретные профили и идентификаторы в общий чат. В **Внешний вид** доступны визуальные настройки; они не меняют сетевой протокол или разрешения подписки.

### 14. Если подключилось, но сайты не открываются

1. Проверь, что другой VPN, например Happ, отключён. Не запускай два системных туннеля одновременно.
2. Проверь выбранный сервер и режим **Приложения**. Браузер может быть вне списка режима «Только выбранные», а прямой выход — заблокирован постоянной защитой.
3. Обнови подписку. Для VIORA начни с выданного **WS TLS**. Не добавляй вручную чужие адреса, порты или параметры. Hysteria2 требует доступного UDP; его работа зависит от сети и выданного сервера.
4. Переподключись и проверь обычный HTTPS-сайт и нужную программу. Если не работает один сервис, сравни с другим сайтом. Если разрешённого прямого выхода нет, это не доказывает неисправность браузера.
5. Сохрани время попытки, название сервера, версию приложения, режим приложений и точный текст ошибки. Передай владельцу сервиса без полной ссылки, паролей и токенов. Статус «Подключено» или короткий TCP-пинг не заменяют эту проверку.

Не отключай проверку TLS, антивирус или брандмауэр ради соединения. Не удаляй данные аккаунта и не меняй системные маршруты наугад. Если хочешь отдельно проверить обычный интернет, сначала осознанно выключи постоянную защиту в VIORA, затем отключи VPN. Иначе блокировка ожидаемо сохранится.

### 15. Частые ошибки

- **Не удалось обновить подписку.** Прежние серверы сохранены. Проверь доступ к сети, срок и правильность HTTPS-ссылки; при отзыве устройства потребуется разрешение владельца. Старые параметры могут оставаться в списке, даже если сервер их больше не принимает.
- **Служба VIORA не запущена / недоступна.** Закрой приложение через трей и повторно открой. Если ошибка остаётся, запусти официальный текущий установщик для восстановления/обновления и разреши установку службы администратору. Не скачивай отдельные движки со случайных сайтов и не переноси файлы в защищённую папку вручную. Если установщик завершился ошибкой, сохрани его код и локальный журнал для разбора.
- **Ошибка TLS или сертификата.** Проверь дату и время Windows и обнови подписку. Неверный адрес, имя сервера или сертификат должен исправляться у провайдера. Параметры `insecure`, `allowInsecure` и `skip-cert-verify`, отключающие проверку сертификата, не являются решением.
- **Несовместимые записи.** Проверь поддерживаемые протоколы и расширения по ссылке на форматы импорта. Ошибка разбора файла не означает, что нужно заменять конфигурацию случайным JSON из интернета.
- **Не выбран список приложений.** Для режимов с выбором добавь нужные EXE либо верни **Все через VPN**, если именно этого хочешь. Проверь сочетание с постоянной блокировкой.
- **Hysteria2 не соединяется.** Убедись, что профиль выдан провайдером и сеть пропускает UDP. TCP-пинг не проверяет HY2. Для собственной подписки можно вернуться к выданному WS TLS; наличие другого клиента не гарантирует поддержку всех параметров его профиля в VIORA.

### 16. Аварийное снятие блокировки администратором

Этот способ нужен только если ты включил постоянную блокировку VIORA, потерял доступ к интернету и не можешь выключить её через приложение. В обычной ситуации используй **Выключить защиту** в настройках.

Администратор компьютера может открыть PowerShell **от имени администратора** и выполнить штатную команду из установленного компонента VIORA:

```powershell
& "$env:ProgramFiles\Viora\Engine\viora_firewall.exe" disable
```

Команда снимает политику VIORA и возвращает возможность прямого выхода. Используй её только если именно это намерен сделать. Она не чинит подписку или сервер и не должна превращаться в обычный шаг подключения. Не сбрасывай весь брандмауэр Windows. Если установленный файл отсутствует или команда завершается ошибкой, сохрани сообщение и обратись к администратору; не подменяй его неизвестным EXE.

### 17. Самостоятельная проверка после обновления

Это чеклист для проверки на твоём ПК, а не перечень уже выполненных разработчиком действий. Проверяй в удобный момент, не запускай одновременно два системных VPN и заранее учитывай состояние постоянной блокировки.

1. Проверь версию **1.1.0, сборка 37** в приложении. Сравни аккаунт, HWID, сохранённые подписки, отдельные серверы и настройки с состоянием до обновления; не сбрасывай их ради проверки.
2. Проверь импорт и обновление своей подписки. При желании протестировать ошибку редактирования используй заведомо недоступную HTTPS-ссылку без чужих токенов: сохранение должно завершиться ошибкой, а прежняя ссылка и серверы — остаться. Не удаляй рабочий источник для такого теста.
3. Подключись к выданному серверу и открой обычный HTTPS-сайт, Telegram и Discord. Если нужны звонки или голос, отдельно проверь голосовое соединение: открывшаяся страница не проверяет весь UDP-трафик.
4. В браузере, который действительно направлен через VPN, проверь внешний IP через сервис определения адреса. Сопоставь с ожидаемым адресом выхода провайдера. Для прямых исключений ожидается другой маршрут; проверка IP одной вкладки не доказывает отсутствие всех утечек.
5. Во время соединения смени сервер, дождись результата и снова проверь трафик. Проверь обычное отключение, сворачивание крестиком, открытие из трея и полный выход. При полном выходе VPN останавливается, но постоянная блокировка остаётся.
6. Проверь нужный режим приложений и собственные прямые правила на выбранных программах. При выключенной постоянной блокировке прямые исключения работают обычным интернетом; при включённой они не должны получать прямой выход. Не принимай ожидаемую блокировку за потерянную настройку.
7. Снова открой VIORA и проверь выбранное автоподключение при открытии. Это отдельно от запуска при загрузке Windows. Если планируешь проверять перезагрузку, заранее помни: при постоянной блокировке сеть может ждать ручного открытия VIORA и подключения.
