# Проверка безопасности VIORA 1.0.0

Проверялись существующие исходники и реальные зависимости. Результат — исправления
в коде, новые регрессионные проверки и пересборка компонентов. Проверка не доказывает
отсутствие неизвестных уязвимостей.

| Приоритет | Подтверждённая проблема | Исправление |
| --- | --- | --- |
| CRITICAL в библиотеке | Pillow 12.3.0: известные ошибки декодирования, в том числе CVE-2026-112403; preview принимает недоверенные изображения | Supplemental lock Pillow 13.0.0 с официальными хешами; отказ старому/неизвестному декодеру до разбора изображения |

## Проверка зависимостей

[GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809) опубликована после предыдущего
аудита и затрагивает проверку сертификатов Go 1.27.2. Android AAR для трёх ABI,
desktop Xray и helpers пересобраны настоящим Go 1.27.3. Полученный через зеркало
архив инструментария принят только после точного совпадения SHA-256 с официальными
метаданными Go; проверка TLS не отключалась.

GitHub Reviewed Advisory API проверил 102 закреплённые координаты Go/Pub/Python.
Версия compress 1.18.2 совпадает с HIGH
[GHSA-259r-337f-4rfw](https://github.com/advisories/GHSA-259r-337f-4rfw), но уязвимый
пакет S2 и функции словарей отсутствуют в фактических desktop imports и Android
vendor. Используется Zstandard через uTLS. Модуль сохранён; вывод о недостижимости
нужно повторить при изменении импортов. Это не заявление об отсутствии всех CVE.
OSV batch и полный govulncheck database scan были недоступны из текущей сети.

## Область действия серверных исправлений

Python-исправления находятся в исходниках и требуют отдельного развёртывания.
Установка APK/EXE не меняет бот. Версии библиотек и конфигурация боевого сервера
удалённо не проверены, его безопасность этой публикацией не подтверждается.
После развёртывания нового кода preview откажет старому Pillow до обновления
зависимости по requirements-control.txt. Этот файл дополняет существующее
окружение бота, а не является полным production lock; Pillow 13 требует Python 3.11+.

## Что осталось непроверенным

Реальный desktop-туннель, IP/DNS/IPv6/WebRTC-утечки, работа WFP/nft на живом трафике,
загрузка ПК с активной защитой, длительная нагрузка, установка и удаление пакетов
на каждом дистрибутиве не проверялись. Fedora/Arch получают пакеты общего Linux
бинарника; успешная проверка содержимого не заменяет запуск на этих ОС.
Android проверяется отдельно на подключённом телефоне; результат указан в
[примечаниях выпуска](release-1.0.0.md).

При обновлении старой включённой защиты Windows без записи владельца потребуется
однократная административная миграция из инструкции. Защита автоматически не снимается.
Windows/Linux пока без подписи издателя. Ключ Android сохранён за пределами репозитория.
