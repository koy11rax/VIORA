# VIORA 1.0.5 — новый модуль подключения Windows

Обновление для Windows 10/11 x64. Туннель Windows теперь создаёт sing-box;
Xray используется для связи с VPN-сервером. Прежний Xray TUN на Windows
больше не запускается. Владелец проверил эту сборку на своём ПК и подтвердил
работу подключения.

## Установка

1. Закройте VIORA через меню значка в трее → «Выйти из VIORA».
2. Скачайте `Viora-Windows-1.0.5-Setup.exe` и установите поверх текущей версии.
3. Запустите VIORA и подключитесь к выбранному серверу.

Установщик позволяет выбрать папку интерфейса. Настройки, аккаунт, подписка
и существующий HWID сохраняются. Служба и движки устанавливаются в защищённую
системную папку; повторное подтверждение администратора при каждом подключении
не требуется. MSI предоставлен как альтернативный пакет установки.

## Что изменилось

- Полностью переработан модуль подключения Windows: sing-box TUN → локальный
  защищённый SOCKS → Xray/VLESS. Поддержка WS TLS, XHTTP TLS и REALITY сохранена.
- Добавлен последовательный запуск и контроль обоих компонентов. При остановке
  одного второй завершается; переподключение ограничено числом попыток.
- Сохранены правила маршрутизации и режимы отдельных приложений. Постоянная
  блокировка по-прежнему запрещает прямые исключения.
- Исправлены упаковка Wintun и запуск службы установщиком.
- Убраны недостоверные TCP-замеры во время активного VPN; локальное
  подтверждение TUN больше не выдаётся за задержку удалённого сервера.
- Улучшены сообщения об ошибках и диагностика без сохранения секретных ссылок,
  адресов назначения и исходных строк журнала.

## Проверки

237 проверок Go прошли; системная проверка установленной службы пропущена.
Проверки конфигураций обоих движков, Flutter и содержимого установщика прошли.
Владелец подтвердил работоспособность версии 1.0.5 на своём ПК. Изолированные
проверки агента не включали VPN и не отключали Happ.

Отдельные проверки утечек DNS/IPv6, длительной работы и сетевых переходов
не выполнены. Подробности и контрольные суммы компонентов:
[техническое описание](windows-connectivity-1.0.5.md).

## Файлы выпуска

- `Viora-Windows-1.0.5-Setup.exe` — обычный установщик.
- `Viora-Windows-1.0.5.msi` — пакет Windows Installer.
- `Viora-Windows-1.0.5-source.zip` — исходники, инструкции и закреплённые
  архивы исходников сторонних компонентов.
- `SHA256SUMS-Windows-1.0.5.txt` — контрольные суммы опубликованных файлов.
- `COPYING-sing-box-GPL-3.0.txt` — полный текст GPL v3 для sing-box.

Android остаётся на [версии 1.0.2](https://github.com/koy11rax/VIORA/releases/tag/v1.0.2),
Linux — на [версии 1.0.0](https://github.com/koy11rax/VIORA/releases/tag/v1.0.0).
Новые APK, DEB, RPM и Arch-пакеты в этот выпуск не входят.
