# VIORA 1.1.0: сторонние подключения

В этом выпуске публикуются только Android и Windows. Подготовка Linux 1.1.0
отменена владельцем; опубликованные Linux-пакеты остаются версии 1.0.5.

Общий интерфейс Android, Windows и Linux принимает отдельные подключения
VLESS, VMess AEAD, Trojan, Shadowsocks AEAD и Hysteria2, включая Salamander.
Подписки можно загрузить по HTTPS, вставить списком или открыть из файла.
Поддержанные сочетания, форматы и ограничения перечислены в
[описании импорта](multi-protocol-import.md).

Существующие аккаунты, настройки, список приложений и HWID не сбрасываются.
HWID передаётся только собственной подписке VIORA; при HTTPS-переходах на
сторонний адрес эти заголовки не переносятся. Из сторонних JSON/YAML берутся
параметры сервера, а чужие DNS, маршруты и входящие порты не исполняются.
Число несовместимых записей показывается при импорте.

Сетевые компоненты сохраняют существующую архитектуру. Desktop использует
sing-box TUN и Xray для протоколов; Android сохраняет Xray/VpnService. Проверка
сертификатов не отключается. Новый Android AAR исправляет обработку отказа
защиты TCP/UDP-сокета: отказ прекращает подключение. Исправлены чтение адреса
Hysteria2 и поддержка новых профилей в плитке быстрых настроек.

## Выполненные проверки исходников

30.10.2026: полный Flutter-набор — 224 успешных теста и 6 пропусков;
статический анализ — без замечаний. Включены прежние профили/подписки,
подключение/отключение, хранение, интерфейс и импорт нескольких протоколов.

Desktop: 13 полных конфигураций, созданных production Dart TunnelConfig,
прошли native sanitizer и реальную передачу через временные локальные серверы.
Во всех случаях проверен отказ при неверных данных доступа; для восьми TLS
вариантов — отказ при неверном имени сертификата. Найденное расхождение
Shadowsocks DTO устранено: отсутствующие необязательные streamSettings
восстанавливаются только для этого протокола.

Android-source: 20 TCP/UDP-проверок прошли через закреплённый исходный движок,
включая Hysteria2 с Salamander, VMess/Trojan WS TLS и три метода Shadowsocks.
Первоначальные таймауты были вызваны блокировкой локальных адресов в тестовом
сервере. Исправлена только политика этой схемы: разрешены два временных
loopback-адреса, остальные назначения заблокированы.

Дополнительно 13 полных конфигураций Dart прошли 26 TCP/UDP-передач через
Android-движок; семь отрицательных TLS/auth сценариев отклонены. Java и Kotlin
проверки чтения адреса и плитки быстрых настроек прошли по три теста.

На Linux повторены реальные loopback-подключения всех 13 вариантов через
Linux Xray. Это отдельный результат Linux, а не перенос результатов Windows.

Установщик Windows r2: независимо сопоставлены 36 файлов пакета с исходной
полезной нагрузкой, версии, защищённые пути, цель ярлыка и метаданные запуска
службы. Версия MSI — 1.1.0, интерфейса — 1.1.0+36. Встроенный MSI установщика
EXE совпадает побайтово с проверенным файлом. Установка и служба на основной
Windows-машине не запускались.

Эти результаты не подтверждают работу внешнего сервера или установленного APK
на физическом телефоне. HAPP, маршруты и VPN-службы Windows при этих проверках
не переключались. Результаты готовых пакетов и отдельных Linux-сеансов
должны указываться отдельно от проверок исходников.
