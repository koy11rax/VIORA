## Возможности

- Импорт серверов и подписок по ссылке, через буфер обмена и QR.
- Telegram-вход, продление с инструкцией оплаты, подписка и управление устройствами.
- Правила маршрутизации и выбор программ для VPN или обычного интернета.
- Отключаемый прямой доступ к российским сервисам.
- Обновление подписки и TCP-пинг с главного экрана.
- Восстановление подключения, светлая/тёмная темы и настройка внешнего вида.
- Android: уведомление с трафиком и отключением, системный always-on и lockdown.
- Windows/Linux: трей, время и трафик; в 0.8.2 добавлена постоянная системная блокировка без VPN.
- Административный кабинет владельца с проверкой роли сервером.

Функции аккаунта, оплаты и администрации требуют работающего сервера Viora VPN и соответствующих прав. Серверная часть, базы пользователей, подписки и ключи подписи в репозиторий не входят.

## Статус проверки

Android 0.7.4 проверен владельцем на телефоне: браузер, Telegram/exteraGram, строгая защита, переходы Wi-Fi/LTE и восстановление после перезагрузки. Проверки других моделей и инструментальная проверка утечек не проведены.

Desktop 0.8.2 — **предварительный выпуск для приёмки**. Прошли анализ кода, проверки интерфейса/mock-IPC, сборка и проверка пакетов. Реальные VPN-соединения, блокировка трафика, обрыв и перезагрузка с активной защитой не проверялись по поручению владельца. Для Fedora/Arch подготовлены пакеты общего Linux-бинарника; запуск на этих дистрибутивах отдельно не проверен.

Постоянная блокировка сохраняется после выхода и блокирует прямые исключения. На Linux ранняя защита рассчитана на systemd с NetworkManager/systemd-networkd. Автоматический запуск самого VPN после перезагрузки ПК этим не добавлен. Перед включением прочитай [инструкцию восстановления](docs/desktop-user-guide-0.8.2.md).

## Исходники и сборка

- apps/client — общий Flutter-клиент и платформенные runners.
- desktop — привилегированные компоненты Windows/Linux и правила упаковки.
- third_party — закреплённая интеграция Android-движка и исходники зависимостей.
- toolchains/xray-main/source.zip — закреплённые исходники desktop Xray; Wintun поставляется отдельным официальным архивом.
- scripts — сборка, проверки и упаковка.

[Сборка Android](docs/android-source-build.md), [сборка Windows/Linux](docs/desktop-source-build-0.8.2.md). Для точного исходного состояния Android 0.7.4 используй тег v0.7.4; текущая ветка main содержит обновления Desktop 0.8.2. Ключи подписи и локальные настройки SDK не публикуются.
