# VIORA Android 1.0.2

Исправления восстановления соединения и диагностики Android после проблемы
«VPN включён, но ничего не загружается».

- Исправлены обработка смены сети и восстановление соединения Android.
- Обновлённые параметры активной подписки применяются с переподключением.
- Исключено одновременное обновление подписки при смене конфигурации.
- Выбранный способ подключения сохраняется при обновлении параметров подписки;
  XHTTP не сбрасывается на первый WS только из-за изменения ссылки.
- Исправлена обработка нового подключения из быстрых настроек после ошибки.
- Проверка пинга теперь различает открытый порт и ответ HTTPS через VPN.

171 автоматический тест пройден, 5 пропущены; анализатор без замечаний.
На затронутом телефоне пользователь подтвердил работу браузера и Telegram на
XHTTP TLS. После установки итоговой сборки HTTPS-проверка через VPN также
успешна. Работа REALITY в сети пользователя не подтверждена; результаты
XHTTP не распространяются на все транспорты и сети.

Установка поверх прежней VIORA сохраняет аккаунт, подписки и настройки.
Предупреждение Google Play Защиты для приложения вне магазина может сохраняться.
