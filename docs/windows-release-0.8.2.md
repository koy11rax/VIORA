# VIORA Windows 0.8.2 (27) — постоянная системная защита

Добавлена постоянная блокировка без VPN. Windows использует отдельный WFP provider/sublayer, persistent ALE/forward filters и boot-time IP filters. Linux использует свою nftables inet-таблицу и раннюю загрузку systemd до NetworkManager/systemd-networkd. Правила других firewall не сбрасываются.

Защита снимается отдельной командой, сохраняется при выходе, сбое и обновлении, удаляется при полном удалении пакета. Строгая конфигурация блокирует все freedom/direct outbounds. Для запуска с доменным VPN-адресом используется ограниченный HTTPS bootstrap; Host/SNI сохраняются. На Linux внешние VPN-пакеты помечаются привилегированным socket mark; произвольный трафик root не разрешается автоматически. На Windows разрешение движка ограничено защищённым путём и токеном SYSTEM.

Кнопки «Включить защиту», «Выключить защиту», «Проверить состояние» находятся в настройках соединения. Показание включённой защиты требует успешного ответа привилегированного компонента. Ошибка или недоступная служба не считаются успехом. HWID/Android не менялись.

VPN и системная блокировка на рабочем компьютере не запускались. Реальные сетевые проверки и приёмка перезагрузки с включёнными фильтрами не выполнялись по запрету владельца. Результаты сборки и проверок приведены ниже; они не заменяют проверку защиты от утечек.

Инструкция и восстановление: [desktop-user-guide-0.8.2.md](desktop-user-guide-0.8.2.md).

## Проверки кода и Windows-пакета

Flutter analyze без замечаний на Windows и в Linux VM. Все 20 проверок интерфейса, буфера, mock-IPC и контроллера прошли после обновления устаревшего ожидания запрета desktop strict. Реальные службы и движок в этих тестах заменены тестовыми реализациями; VPN не запускался. Два Go-теста строгой политики прошли; Go vet для Windows/Linux чистый. WFP-компонент скомпилирован MSVC /W4 /WX.

Windows EXE 0.8.2, UI 0.8.2+27. Проверены 30 файлов MSI, SHA-256 каждого файла, ярлыки, выбор папки, защищённый Engine, установка службы и deferred SYSTEM-действие снятия защиты только при полном удалении. Сам MSI не устанавливался. Linux nftables прошёл --check без применения; после проверки таблица VIORA и файл включения отсутствовали. Проверка загрузки ОС/обрыва с активными правилами не проводилась.
