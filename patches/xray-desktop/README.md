# Исправления настольного Xray

Базовый Xray: `701af60772cda123492f86e383e1fdba066614a9`, MPL-2.0.
Исходный файл: `transport/internet/websocket/dialer.go`.
Его SHA-256: `247b1512b2c868f7766a7f40dca88ab69ce248ddc5a58bd9ae57d06deaa01c56`.
Полный изменённый файл находится рядом: `websocket_dialer.go`.
Лицензия Xray включена в `apps/client/assets/licenses/Xray-MPL-2.0.txt`.

Правка сохраняет проверку TLS-сертификатов, имени сервера, SNI, HTTP Host,
настройки транспорта и существующие методы `LocalAddr`/`RemoteAddr`.
Изменены только передача контекста через `NetDialContext` и
`NetDialTLSContext`, закрытие соединения после ошибки TLS/проверки имени и
фиксированная отметка `websocket connection established` после успешного
`dialer.DialContext`. Эта отметка не содержит адреса и не утверждает доступность
целевого сайта: она подтверждает завершение внешнего WebSocket-рукопожатия.

Скрипт `scripts/build-desktop-core.ps1` проверяет SHA-256 исходного файла и
создаёт временный Go `-overlay` для Windows и Linux. Сам каталог исходного
Xray не редактируется. Временные абсолютные пути формируются при сборке;
пользовательских путей в этой копии исходников нет.

## Частично полученная запись TLS

Второй overlay — `tls_sniff.go`, исходный файл
`common/protocol/tls/sniff.go`. SHA-256 исходника:
`75f4b79a0f98dda3a615ab1b34f202458a3ad68d76cd232c64f5b6cd8640426c`.
Для уже распознанного заголовка TLS, когда заявленная запись ещё не получена
полностью, возвращается существующий `ErrProtoNeedMoreData`. Ранее
`ErrNoClue` тратил ограниченное число попыток распознавания раньше срока,
из-за чего дробление ClientHello могло лишать доменные правила имени SNI.
Формат TLS, проверка сертификата и предел ожидания dispatcher не меняются.

Оба базовых исходника проверяются по SHA-256 перед сборкой; overlay не
редактирует upstream. Android-библиотека этими настольными правками не меняется.

Регрессии: `tests/xray-websocket/README.md` и `tests/xray-tun/README.md`.
Воспроизведение старой ошибки
отдельно включается параметром `--verify-baseline`.
