# VIORA 1.1.0 для Android

Добавлены сторонние подписки и отдельные подключения: VLESS, VMess AEAD,
Trojan, Shadowsocks AEAD и Hysteria2 с Salamander. Поддержка ограничена
перечисленными в документации форматами; неизвестные параметры и небезопасные
настройки TLS не принимаются молча.

Подключения доступны и из плитки быстрых настроек. Существующие данные,
выбранные приложения, подписки VIORA и подпись APK сохранены.

Сборка 37 добавляет раздел «Сохранённые подключения»: редактирование и
удаление HTTPS-ссылок подписок и отдельных серверов. При неудачной замене
прежние подключения сохраняются; активный удаляемый сервер сначала отключается.
Полные ссылки по умолчанию скрыты. Это обновление устанавливается поверх
предыдущей сборки 1.1.0 (36).

Устанавливается поверх официальной VIORA. Системное разрешение Android VPN
остаётся обязательным. Это подписанный APK для Android 8.0 и новее.

Нативные локальные обмены TCP/UDP и отказы TLS/авторизации проверены.
Реальное подключение новой сборки на пользовательском телефоне пока не проверено.
