# VIORA Linux 1.0.5

Обновление Linux на основе Windows 1.0.5: общий актуальный интерфейс,
sing-box как TUN-компонент и Xray для транспорта VLESS. Аккаунты, подписки,
HWID, выбранные приложения и пользовательские настройки при обновлении
не сбрасываются. Windows-компоненты WFP и Wintun на Linux не устанавливаются.

## Установка и обновление

Пакеты рассчитаны на Linux **x86_64**, glibc 2.35+, GTK 3, Secret Service,
polkit, nftables, iproute2, ca-certificates и systemd-resolved. Для ранней постоянной защиты требуется
systemd с NetworkManager или systemd-networkd.

- Debian/Ubuntu: `sudo apt install ./Viora-Linux-1.0.5-amd64.deb`.
- Fedora: `sudo dnf install ./Viora-Linux-1.0.5-1.x86_64.rpm`.
- Arch: `sudo pacman -U ./viora-bin-1.0.5-1-x86_64.pkg.tar.zst`.

Закрой VIORA перед обновлением. Обновляй установленный пакет штатной командой
менеджера пакетов. Полное удаление старой версии перед обновлением не требуется:
оно снимает постоянную защиту, тогда как штатное обновление её сохраняет.

Интерфейс работает от обычного пользователя. Системное разрешение polkit
запрашивается отдельным VPN-помощником, а не всем приложением. Установка сама
VPN и постоянную блокировку не включает, сетевые службы не перезапускает.
Приложение устанавливается в `/usr/lib/viora`, команда запуска — `viora`.
TLS использует системное хранилище доверенных CA Linux; проверка имени сервера
и цепочки сертификата сохраняется. Пользовательские VPN-профили не могут
отключать проверку сертификатов или загружать собственный доверенный CA.

Все три формата содержат одинаковый бинарный комплект, собранный на Ubuntu
22.04; RPM и Arch-пакет не означают отдельную компиляцию в Fedora или Arch.
Совместимость конкретных выпусков этих дистрибутивов требует приёмки на них.
ARM, OpenRC, Fedora Atomic, Flatpak и старые версии glibc этим набором не покрыты.

## Первый запуск

Открой VIORA через меню приложений или `viora`. Разблокируй системную связку
ключей Secret Service, затем импортируй подписку из бота и выбери сервер.
В режиме «Только выбранные приложения» сначала выбери нужные программы.
Для Flatpak, оболочек и нескольких процессов может потребоваться фактический
исполняемый файл. Выбор программ можно импортировать и экспортировать через
буфер обмена. Права административного кабинета подтверждает сервер.

Если Linux не может определить исполняемый файл соединения, запрос в режимах
выбора приложений блокируется. Неопределённое приложение не переводится
автоматически в прямую сеть или VPN вопреки выбранному режиму.

Трей использует AppIndicator/StatusNotifier. В GNOME может потребоваться
расширение индикаторов. Если хост трея отсутствует, крестик минимизирует окно,
чтобы приложение оставалось доступным. В меню доступны подключение, серверы,
подписки, пинг, настройки и выход. Полный выход останавливает VPN.

## Постоянная защита

Сначала сохрани подписку и сервер. Отключи VPN, затем открой «Настройки →
Соединение и защита → Постоянная блокировка без VPN» и подтверди включение.
Состояние показывается после ответа системного компонента.

При включённой постоянной блокировке интернет без VPN недоступен после
отключения, закрытия VIORA и перезагрузки. Прямые правила, российские сервисы,
локальная сеть и исключённые приложения тоже блокируются. Сам VPN при загрузке
Linux автоматически не запускается: автоподключение применяется при открытии
VIORA. Подписки и управление аккаунтом без VPN могут быть недоступны.

Для возврата обычного интернета отключи VPN, дождись остановки и выключи защиту
в настройках. Если интерфейс недоступен, выполни:

```sh
sudo /usr/lib/viora/viora_tunnel --protection recover
```

Если компонент уже удалён вручную, удали только правила VIORA:

```sh
sudo nft delete table inet viora_lockdown
sudo rm -f /var/lib/viora/protection.enabled
sudo systemctl daemon-reload
```

`nft` может сообщить, что таблица уже отсутствует. Не сбрасывай другие правила
firewall. Штатное полное удаление пакета снимает правила VIORA; обновление
сохраняет выбранную защиту. Если ранее включённая защита не загрузится до сети,
зависимости NetworkManager/systemd-networkd могут остановить их запуск до
восстановления.

## Целостность, лицензии и ограничения проверки

Рядом с каждым пакетом есть файл SHA-256. Из каталога с обоими файлами выполни,
например, `sha256sum -c Viora-Linux-1.0.5-amd64.deb.sha256`.
Контрольная сумма проверяет целостность и не заменяет подпись издателя.
Пакеты пока не подписаны доверенным ключом. Не отключай общую проверку подписей
менеджера пакетов.

Происхождение sing-box, GPL и его исходники находятся в
`/usr/lib/viora/licenses`. Исходники клиента и закреплённых компонентов
предоставляются отдельно как `Viora-Linux-1.0.5-source.zip`.

Сборка и проверка содержимого пакетов не доказывают отсутствие сетевых утечек.
Фактические результаты тестов и непроверенные сценарии указаны в примечаниях
к выпуску. Реальная сеть основной Windows-машины при подготовке не меняется,
Happ не отключается. Установка в Fedora/Arch и работа под разными рабочими
столами требуют отдельной приёмки.
