# Проверки Android 1.1.1, сборка 41

Изменения, воспроизведение, результаты автоматических и физических проверок,
контрольная сумма APK и ограничения собраны в
[отчёте об исправлении](subscription-recovery-1.1.1.md).

Для пользователя: [заметки выпуска](android-release-notes-1.1.1.md),
[установка и настройка](android-user-guide.md).

Нативный движок не менялся. Его исходный AAR закреплён SHA-256
`8571167d3afc4df1dd7507226b7091561d709a5eb09d23064823f7484146643f`;
все три упакованные библиотеки проверены относительно него после штатного strip.
Сборка APK выполнена с прежним ключом подписи. Закрытый ключ не публикуется.

Новые готовые сборки Windows и Linux в этот выпуск не входят.
