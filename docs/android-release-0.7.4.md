## Изменение

VPN больше не объявляет фиктивный IPv6-адрес и маршрут в TUN. Поддерживаемая
семья остаётся IPv4; Android блокирует не настроенную семью IPv6 самостоятельно.
Не вызываются allowFamily(AF_INET6) и allowBypass. Старые DNS-адреса и необязательные
маршруты подсетей также не могут неявно разрешить IPv6. Правило блокировки IPv6
в движке и пустые ответы AAAA сохранены как дополнительная защита.

Основание: [VpnService.Builder.allowFamily](https://developer.android.com/reference/android/net/VpnService.Builder#allowFamily(int)).
Это исправление объявления возможностей интерфейса, а не установленная причина
зависания синхронизации exteraGram.

## Диагностика предыдущей версии

Владелец подтвердил работу сайтов и Telegram Web через VIORA 0.7.3 в режиме
session без системного lockdown. Официальный Telegram работает через VIORA и
INCY с той же подпиской; без VPN не подключается. exteraGram с обоими VPN
показывает «Обновление», хотя отправляет сообщения. Данные клиента не очищались.
Эти результаты не подтверждают поломку всех VPN и не устанавливают причину
зависания exteraGram. Приёмка продолжается с официальным Telegram.

## Проверено 12 октября 2026

- Flutter analyze: без замечаний. 60 тестов прошли, 4 необязательных пропущены.
- Release APK собран; apksigner подтвердил подпись v2 и прежний сертификат.
- Установлен поверх 0.7.3 на TECNO LJ9 / API 36; настройки и выбранный сервер
  сохранились. Версия установленного пакета подтверждена: 0.7.4, code 24.
- Подключение WS TLS запустило VPN. В Android LinkProperties только адрес
  26.26.26.1/30, DNS 26.26.26.2 и системный `::/0 unreachable`; фиктивного IPv6
  адреса нет. Это проверка конфигурации интерфейса, не полная проверка утечек.
- На момент подключения системные always-on и lockdown выключены; в приложении
  сохранён session и исходный список выбранных приложений.

Владелец подтвердил работу Яндекс Браузера и официального Telegram на 0.7.4
в режиме session. Без lockdown строгий режим отказал с корректной инструкцией,
VPN-интерфейс не остался активным. Затем владелец включил оба системных
переключателя; always_on_vpn_app и lockdown=1 подтверждены, строгий VPN
подключился. Владелец подтвердил работу браузера и официального Telegram с
включённой строгой защитой, а также восстановление после переходов Wi-Fi → LTE
и LTE → Wi-Fi без ручного переподключения.

После перезагрузки Android восстановил службу VIORA; подключение и lockdown=1
подтверждены через ADB без запуска приложения со стороны проверки. Владелец
подтвердил автоматическое восстановление без открытия VIORA, работу браузера,
официального Telegram и exteraGram. Зависание exteraGram исчезло после обновления
и перезагрузки; это не устанавливает единственную причину прежней проблемы.

По решению владельца подготовлен пакет для распространения без дополнительной
приёмки на других телефонах. Отдельная остановка процесса системой,
инструментальная проверка утечек и другие Android-устройства не проверены.
Не считать эти проверки пройденными по факту запуска движка или роста трафика.

Play Protect не отключался; предупреждение принято владельцем. Windows и Linux
в этом выпуске не пересобирались. Пакет включает установочный APK, инструкцию,
описание версии, лицензии, SHA256SUMS.txt, release.json и Android-исходники:
Flutter-клиент, тесты, Java-интеграцию и закреплённый движок с Go-зависимостями.
Архив Android-исходников не содержит серверную часть и ключи подписи.
